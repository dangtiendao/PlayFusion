# Web Game Hub (PlayFusion)

Nền tảng Web Game Hub chơi game online & offline xây dựng trên React + Vite + TypeScript.

## Yêu cầu môi trường

- **Node.js**: `>= 20.0.0` (Khuyến nghị Node 20 LTS)
- **npm**: `>= 9.0.0`

## Hướng dẫn cài đặt & Chạy

### 1. Cài đặt dependencies

```bash
npm install
```

### 2. Chạy môi trường phát triển (Dev)

```bash
npm run dev
```

### 3. Kiểm tra kiểu dữ liệu (TypeScript typecheck)

```bash
npm run typecheck
```

### 4. Build sản phẩm (Production build)

```bash
npm run build
```

### 5. Preview bản build

```bash
npm run preview
```
