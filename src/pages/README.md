# Application Pages (`src/pages/`)

Thư mục chứa các màn hình và route views chính của ứng dụng Web Game Hub:

- **Các màn hình**: Home (Lobby chọn game), Match (Trận đấu đang diễn ra), Profile (Thống kê cá nhân), Leaderboard (Bảng xếp hạng), History (Lịch sử đấu), Admin (Quản trị).
- **Trách nhiệm**: Kết hợp các components và business logic để render trang hoàn chỉnh theo URL.
