# Shared Components (`src/components/`)

Thư mục chứa các thành phần giao diện dùng chung xuyên suốt hệ thống Web Game Hub:

- **UI cơ bản**: Button, Modal, Drawer, Toast, Card, Dropdown, Skeleton loading.
- **Thành phần Game Hub đặc thù**: PlayerBadge, AvatarFrame, TimerCountdown, ResultOverlay, ScoreBoard.
- **Thiết kế**: Tuân thủ triệt để nguyên lý Mobile-First, dark mode class, và semantic tokens.
