# Core Modules (`src/core/`)

Thư mục chứa các module nền tảng lõi phục vụ trải nghiệm chơi game:

- **GameShell**: Khung vỏ bao bọc màn chơi, điều phối layout responsive, header info, và surrender/rematch dialogs.
- **Sub-systems**: Quản lý âm thanh hiệu ứng (Audio), lưu trữ client cache (Storage/IndexedDB), và tối ưu tương tác chạm (Input).
- **Phạm vi triển khai**: Sẽ được xây dựng chi tiết tại phase P0.8.
