## 1. Các thành phần đã triển khai

### A. Cấu hình Định tuyến Fallback SPA (`public/_redirects`)

- File [public/\_redirects](file:///e:/Project/PlayFusion/public/_redirects) chứa rule:
  ```
  /*    /index.html   200
  ```
- **Ý nghĩa kỹ thuật**: Hướng dẫn Cloudflare Pages tự động trả về `index.html` cho bất kỳ URL con nào (ví dụ `/caro`, `/profile`, `/settings`), giúp React Router ở client-side xử lý điều hướng mà không bị lỗi 404 Not Found khi người dùng refresh hoặc truy cập trực tiếp URL con.

### B. Cấu hình Caching & Bảo Mật Cơ Bản (`public/_headers`)

- File [public/\_headers](file:///e:/Project/PlayFusion/public/_headers) chứa:
  - Cache dài hạn bất biến cho static assets có hash:
    ```
    /assets/*
      Cache-Control: public, max-age=31536000, immutable
    ```
  - Chống cache cho `index.html` để cập nhật phiên bản mới tức thì ngay khi deploy:
    ```
    /index.html
      Cache-Control: public, max-age=0, must-revalidate
    ```
  - Header bảo mật toàn cục:
    ```
    /*
      X-Content-Type-Options: nosniff
      Referrer-Policy: strict-origin-when-cross-origin
      X-Frame-Options: SAMEORIGIN
      Permissions-Policy: camera=(), microphone=(), geolocation=()
    ```

### C. Cập nhật Tài liệu Vận hành (`README.md`)

- Bổ sung mục "Triển khai Cloudflare Pages", giải thích cơ chế Auto Deploy độc lập với GitHub Actions workflow.

## 3. Checklist Hướng dẫn Thao tác trên Cloudflare Dashboard

1. Truy cập và đăng nhập [dash.cloudflare.com](https://dash.cloudflare.com).
2. Vào **Compute (Workers & Pages)** $\rightarrow$ Chọn tab **Pages** $\rightarrow$ Nhấn **Connect to Git**.
3. Chọn tài khoản GitHub $\rightarrow$ Chọn repository **PlayFusion** $\rightarrow$ Nhấn **Begin setup**.
4. Cấu hình:
   - **Project name**: `playfusion` (URL công khai: `https://playfusion.pages.dev`).
   - **Production branch**: `master` (hoặc `main`).
   - **Framework preset**: `Vite` (hoặc `None`).
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
5. Biến môi trường (**Environment variables**):
   - Thêm biến `NODE_VERSION` = `20`.
6. Nhấn **Save and Deploy**.

## 4. Hướng dẫn kiểm tra sau khi Deploy thành công

1. **Kiểm tra giao diện Desktop & Mobile (4G/5G)**:
   - Mở `https://<project-name>.pages.dev` trên máy tính và điện thoại.
   - Bấm nút "Đánh thường" / "Đánh mạnh" để xác nhận engine chạy tương tác tốt.
2. **Kiểm tra tránh lỗi 404 khi Hard-Refresh**:
   - Truy cập `https://<project-name>.pages.dev/test-route` và nhấn `Ctrl + F5`.
   - Trang web tải lại bình thường, trả về ứng dụng React, không hiện trang lỗi 404 của Cloudflare.
3. **Kiểm tra Header phản hồi (Response Headers)**:

   ```bash
   # Kiểm tra cache immutable của asset:
   curl -I https://<project-name>.pages.dev/assets/index-...js

   # Kiểm tra header bảo mật và cache của index.html:
   curl -I https://<project-name>.pages.dev/index.html
   ```
