## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACT)

### 3.1. Materialized Views & Quyền Truy Cập

- **`public.mv_leaderboard_masters`**:
  - _Công thức_: $\text{ROUND}\left(\frac{\sum (\text{rating} \times \text{games\_played})}{\sum \text{games\_played}}\right)$ với $\text{games\_played} \ge 10$ trong mùa active.
  - _Schema_: `(user_id, display_name, avatar_url, season_id, weighted_rating, games_count, total_games, best_tier_rating, refreshed_at)`
- **`public.mv_leaderboard_grinders`**:
  - _Công thức_: $\sum(\text{amount})$ từ `wallet_transactions` (`type = 'match_reward' AND amount > 0`) trong mùa active.
  - _Schema_: `(user_id, display_name, avatar_url, season_id, earned_coins, match_rewards_count, refreshed_at)`
- _Quyền_: `GRANT SELECT ON public.mv_leaderboard_masters, public.mv_leaderboard_grinders TO authenticated;` (REVOKE anon).

### 3.2. pg_cron Jobs

- `wgh_refresh_masters` (`*/10 * * * *`): `REFRESH MATERIALIZED VIEW CONCURRENTLY public.mv_leaderboard_masters;`
- `wgh_refresh_grinders` (`2-59/10 * * * *`): `REFRESH MATERIALIZED VIEW CONCURRENTLY public.mv_leaderboard_grinders;`

### 3.3. TypeScript Repository API (`src/repositories/globalLeaderboardRepository.ts`)

```typescript
import {
  globalLeaderboardRepository,
  invalidateGlobalLeaderboard,
} from '@/repositories/globalLeaderboardRepository';

// 1. Lấy Top 100 Cao Thủ
const masters: MasterEntry[] = await globalLeaderboardRepository.getMasters(100);

// 2. Lấy Top 100 Chăm Chỉ
const grinders: GrinderEntry[] = await globalLeaderboardRepository.getGrinders(100);

// 3. Lấy Thứ Hạng Cá Nhân Của Tôi
const myRank: MyGlobalRank = await globalLeaderboardRepository.getMyGlobalRank('masters');
// myRank = { rank: 12, value: 1540 } hoặc { rank: null, value: null } nếu chưa đủ điều kiện

// 4. Xóa bộ đệm In-Memory (gọi sau settle)
invalidateGlobalLeaderboard();
```

## 4. QUYẾT ĐỊNH THIẾT KẾ TRONG PHASE

| Quyết định                                    | Lý do lựa chọn                                                                                                       | Phương án đã loại bỏ                                                               |
| :-------------------------------------------- | :------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------- |
| **Top 100 Cố Định (Không Keyset Pagination)** | Matview đã tính toán và sắp xếp sẵn, Top 100 tải tức thì $< 1$ ms, tối đa hóa hiệu năng và đơn giản hóa UI.          | Dùng Keyset Pagination phức tạp không cần thiết cho bảng tổng hợp.                 |
| **Gọi thẳng REFRESH trong cron.schedule**     | `REFRESH CONCURRENTLY` không thể thực thi trong multi-statement transaction block hoặc PL/pgSQL function.            | Bọc `REFRESH` trong PL/pgSQL function (bị PostgreSQL báo lỗi transaction context). |
| **Phân quyền tường minh qua GRANT/REVOKE**    | PostgreSQL Materialized Views không hỗ trợ RLS policy. Phải bảo vệ bằng object grants.                               | Bỏ qua phân quyền (bị lộ dữ liệu cho anon bot cào).                                |
| **Không tạo Bảng "Giàu Nhất"**                | Số dư ví (`balance`) và giao dịch nạp/tiêu là thông tin riêng tư nhạy cảm. Chỉ tôn vinh xu cày cuốc từ trận đấu.     | Bảng xếp hạng theo số dư ví (vi phạm bảo mật quyền riêng tư tài chính).            |
| **Minh bạch độ trễ 10 phút trên UI**          | Dữ liệu snapshot Matview có chu kỳ 10 phút. Hiển thị thông báo giúp người dùng không thắc mắc khi vừa kết thúc trận. | Ẩn độ trễ hoặc cố ép Realtime refresh liên tục gây quá tải DB.                     |

## 6. HƯỚNG DẪN VẬN HÀNH

1. **Extension Supabase**:
   - Yêu cầu bật extension `pg_cron` trên Supabase Dashboard trước khi chạy migration (`Database` $\rightarrow$ `Extensions` $\rightarrow$ `pg_cron`).
2. **Chạy Migration**:
   - Thực thi file [`supabase/migrations/0023_global_leaderboards.sql`](file:///e:/Project/PlayFusion/supabase/migrations/0023_global_leaderboards.sql) trên SQL Editor.
3. **Lệnh Mồi Dữ Liệu Lần Đầu (Production Seeding)**:
   ```sql
   REFRESH MATERIALIZED VIEW public.mv_leaderboard_masters;
   REFRESH MATERIALIZED VIEW public.mv_leaderboard_grinders;
   ```
4. **Kiểm Tra Trạng Thái pg_cron**:
   ```sql
   SELECT jobid, jobname, schedule, active FROM cron.job WHERE jobname LIKE 'wgh_refresh_%';
   SELECT * FROM cron.job_run_details ORDER BY start_time DESC LIMIT 5;
   ```
