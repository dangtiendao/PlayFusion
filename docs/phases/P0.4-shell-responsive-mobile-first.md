## 1. TÓM TẮT

Phase P0.4 đã xây dựng hoàn chỉnh bộ khung giao diện `AppShell` Mobile-First đạt chuẩn công thái học cho toàn bộ Web Game Hub. Xử lý triệt để các bẫy hiển thị trên iOS/Android (100dvh, safe-area insets 4 hướng, single-scroll container chặn bounce, virtual keyboard resilience), nạp trang bằng `React.lazy` code-splitting, và quản lý Dark Mode tự động đồng bộ theo hệ điều hành qua `useTheme`.

## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. Route Configuration (`src/routes.tsx`)

```typescript
export interface RouteConfig {
  readonly path: string;
  readonly label: string;
  readonly icon?: React.ReactNode;
  readonly element: React.ReactNode;
  readonly showInNav: boolean;
}

export const APP_ROUTES: readonly RouteConfig[];
```

### B. Hook `useTheme` (`src/core/useTheme.ts`)

```typescript
export type ThemeMode = 'light' | 'dark';

export interface UseThemeReturn {
  readonly theme: ThemeMode;
  readonly isDark: boolean;
  readonly toggleTheme: () => void;
  readonly hasManualOverride: boolean;
}

export function useTheme(): UseThemeReturn;
```

_Ví dụ gọi hook trong component:_

```typescript
import { useTheme } from '@/core/useTheme';

function ThemeButton() {
  const { isDark, toggleTheme } = useTheme();
  return <button onClick={toggleTheme}>{isDark ? '☀️' : '🌙'}</button>;
}
```

## 7. ĐẦU VÀO GỢI Ý CHO PHASE KẾ TIẾP (P0.5 — Nền tảng PWA & Khả năng cài đặt)

Phase **P0.5** sẽ biến Web Game Hub thành một ứng dụng PWA hoàn chỉnh (cài đặt lên Home Screen di động, chạy fullscreen không viền browser, và cache assets offline). Cần nắm rõ các đầu vào từ P0.4:

1. **Viewport & Safe-Area đã sẵn sàng**: `viewport-fit=cover` và `100dvh` trong `index.html` và `AppShell.tsx` sẽ hoạt động ở chế độ `display: "standalone"` của PWA một cách hoàn hảo.
2. **Thẻ `<meta name="theme-color">`**: Đã được hook `useTheme` đồng bộ linh hoạt giữa `#f8fafc` và `#0f172a` $\rightarrow$ PWA manifest sẽ cấu hình `theme_color` và `background_color` tương ứng.
3. **Cấu hình Cache Asset**: File `public/_headers` đã cấu hình cache `immutable` 1 năm cho `/assets/*` $\rightarrow$ Service Worker ở P0.5 sẽ phối hợp cache offline thông minh.
4. **Icons PWA**: Cần tạo bộ icon PWA chuẩn kích thước (192x192, 512x512, maskable) đặt trong `public/`.
