## 1. TÓM TẮT

Phase P0.5 đã nâng cấp toàn diện Web Game Hub thành một ứng dụng Progressive Web App (PWA) đạt chuẩn Installability cao cấp. Hệ thống sở hữu Web App Manifest chuẩn mực, bộ icon hoàn chỉnh đa kích thước (192, 512, maskable, iOS apple-touch-icon), cấu hình Service Worker Workbox tối ưu hai tầng cache (Precache 377kB, Runtime Cache hình ảnh & fonts, loại trừ tuyệt đối backend Supabase), hỗ trợ chạy Standalone toàn màn hình, hoạt động Offline mượt mà khi mất kết nối (Airplane Mode), và luồng cập nhật phiên bản 1 chạm an toàn (`UpdatePrompt`) thông qua chiến lược `registerType: 'prompt'`.

## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. Quy trình Phát hành & Bump Version Ứng dụng

Khi có tính năng mới hoặc bản sửa lỗi, chỉ cần cập nhật trường `version` trong [`package.json`](file:///e:/Project/PlayFusion/package.json):

```json
{
  "name": "playfusion",
  "version": "0.5.1"
}
```

Vite build sẽ tự động truyền giá trị này vào hằng số toàn cục `__APP_VERSION__`, cập nhật `APP_CONFIG.version` và tạo ra revision hash mới trong precache manifest của Service Worker $\rightarrow$ Kích hoạt `UpdatePrompt` cho người dùng.

### B. Quy tắc Bất biến về Loại trừ Backend Supabase

```typescript
// BẤT BIẾN: Tuyệt đối KHÔNG cấu hình bất kỳ runtime cache nào cho *.supabase.co hoặc *.supabase.in.
// Mọi request từ Supabase Client (Auth, Realtime, REST API, RPC) sẽ tự động đi thẳng ra internet (NetworkOnly).
```

### C. Hook `useOnlineStatus` (`src/core/useOnlineStatus.ts`)

```typescript
export function useOnlineStatus(): boolean;
```

_Ví dụ sử dụng:_

```typescript
import { useOnlineStatus } from '@/core/useOnlineStatus';

function GameComponent() {
  const isOnline = useOnlineStatus();
  // Cho phép chuyển đổi linh hoạt giữa AI Offline và Đối kháng Online
}
```

### D. Component `UpdatePrompt` & Ràng buộc tương lai trong Trận đấu (Phase P3.x)

```typescript
export function UpdatePrompt(): JSX.Element | null;
```

_Ghi chú kiến trúc P3.x:_ Khi xây dựng Game Engine và Matchmaking ở Phase P3.x, `UpdatePrompt` sẽ được bổ sung điều kiện chặn hiển thị nếu người chơi đang trong trạng thái thi đấu (`isInMatch === true`) nhằm triệt tiêu nguy cơ reload làm xử thua/mất ván cờ.

## 4. QUYẾT ĐỊNH THIẾT KẾ

| Quyết định                                               | Lý do lựa chọn                                                                                     | Phương án đã loại bỏ & Lý do loại                                                           |
| :------------------------------------------------------- | :------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------ |
| **`registerType: 'prompt'`**                             | Giúp người chơi chủ động bấm reload khi rảnh tay; bảo vệ ván cờ đang chơi dở không bị gián đoạn.   | _`registerType: 'autoUpdate'`_: Tự reload bất ngờ làm mất trạng thái ván cờ của người dùng. |
| **`devOptions.enabled = false`**                         | Tránh tình trạng cache cũ che mất code mới đang sửa trên môi trường lập trình `npm run dev`.       | _Bật Service Worker ở local dev_: Gây xung đột và mất thời gian debug cache.                |
| **`navigateFallback: '/index.html'` kèm denylist**       | Đảm bảo SPA routing hoạt động hoàn hảo khi offline mà không chặn các request file tĩnh thực tế.    | _Không cấu hình navigateFallback_: Vào các URL như `/profile` khi offline sẽ bị lỗi mạng.   |
| **Runtime Cache Ảnh (`CacheFirst`) & Loại trừ Supabase** | Tải ảnh nhanh và tiết kiệm băng thông; trong khi dữ liệu Supabase luôn tươi mới và chính xác 100%. | _Cache chung toàn bộ network request_: Làm sai lệch số dư ví và rating Elo.                 |

## 7. ĐẦU VÀO GỢI Ý CHO PHASE KẾ TIẾP (P0.6 — Chuẩn Hóa Plugin Engine & Game Definition)

Phase **P0.6** sẽ thiết lập "trái tim" kiến trúc của Web Game Hub: Chuẩn hóa các interface TypeScript cho Game Engine và Plugin Game. Cần nắm rõ các đầu vào từ P0.5:

1. **Môi trường Thực thi Đa Nền tảng**: Các interface của `Engine<State, Move, Config>` phải là TypeScript thuần túy (không dính React / DOM), vì engine này sẽ chạy được cả trong Client UI, Service Worker/Web Worker, và Supabase Edge Functions (Deno).
2. **Khả năng chơi Offline**: Nhờ nền tảng PWA của P0.5, các engine cờ (Caro, Cờ tướng, Cờ vua) ở Phase P1.x sẽ chạy trực tiếp trên máy người dùng ngay cả khi không có mạng.
3. **Khai báo Manifest Game**: Interface `GameDefinition` chuẩn hóa ở P0.6 sẽ cung cấp metadata để Phase P0.7 nạp động vào Router và Registry của `AppShell`.
