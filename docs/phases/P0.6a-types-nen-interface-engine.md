# Nghiệm thu Phase P0.6a: Types Nền Dùng Chung + Interface Engine<S, M>

- **Mã phase**: `P0.6a`
- **Mục tiêu**: Thiết lập hệ thống kiểu dữ liệu TypeScript thuần túy (Pure TS, Zero DOM, Zero Framework) và interface `Engine<S, M>` làm "Hiến pháp" chuẩn hóa cho toàn bộ Game Engine trong hệ thống PlayFusion.
- **Trạng thái**: ✅ **HOÀN THÀNH 100% (DoD Approved)**

## 1. Các thành phần đã triển khai

### A. Types Nền Dùng Chung (`packages/engines/types/common.ts`)

- `GameMode`: `'solo' | 'vs_ai' | 'local_pvp' | 'online_1v1' | 'online_ffa' | 'online_team'`.
- `PlayerIndex`: `number` (chỉ số ghế 0-based, map 1-1 với `seat_index` trong Supabase DB).
- `MatchOutcome`: `'win' | 'loss' | 'draw'`.
- `ScoringType`: `'win_loss' | 'score' | 'time'`.
- `RatingSystem`: `'elo' | 'glicko2' | 'leaderboard_only'`.
- `AiLevel`: `'easy' | 'medium' | 'hard'`.
- `PlayerOutcome`: `{ playerIndex: PlayerIndex; outcome: MatchOutcome; placement?: number; score?: number }`.
- `TerminalResult`: `{ over: boolean; outcomes?: readonly PlayerOutcome[] }`.
- `MatchResultReport`: Cấu trúc chuẩn hóa gửi lên Edge Function `settle_match` ở Phase P4.2 (`gameId`, `mode`, `participants`, `durationMs`, `movesSerialized`).

### B. Interface Chuẩn `Engine<S, M>` (`packages/engines/types/engine.ts`)

- `EngineInitConfig`: `{ playerCount: number; seed?: string; options?: Readonly<Record<string, unknown>> }`.
- Các hàm bắt buộc:
  - `init(config: EngineInitConfig): S`: Khởi tạo state ban đầu.
  - `legalMoves(state: S, playerIndex: PlayerIndex): M[]`: Sinh toàn bộ nước đi hợp lệ.
  - `applyMove(state: S, move: M, playerIndex: PlayerIndex): S`: Hàm thuần túy, deterministic, không mutate, throw `EngineError` nếu nước đi phạm luật.
  - `currentPlayer(state: S): PlayerIndex`: Xác định người chơi đang tới lượt.
  - `isTerminal(state: S): TerminalResult`: Kiểm tra trạng thái kết thúc ván cờ.
  - `serialize(state: S): string`: Nén state thành chuỗi string gọn nhẹ (đáp ứng 500MB DB quota & replay).
  - `deserialize(data: string): S`: Phục hồi state từ chuỗi string nén (đảm bảo tính toàn vẹn round-trip).
- Các hàm mở rộng tùy chọn:
  - `viewFor?(state: S, playerIndex: PlayerIndex): unknown`: Che thông tin ẩn cho Server Edge Function (Phase P3.x+).
  - `serializeMove?(move: M): string` / `deserializeMove?(data: string): M`: Nén/giải nén nước đi truyền qua mạng Realtime (Phase P3.2).

### C. Class Lỗi Chuẩn Hóa `EngineError` (`packages/engines/types/errors.ts`)

- `EngineErrorCode`: `'ILLEGAL_MOVE' | 'INVALID_STATE' | 'WRONG_TURN' | 'GAME_OVER'`.
- `EngineError extends Error`: Chuẩn hóa lỗi cho cả Client UI và Supabase Edge Functions (HTTP 400 Bad Request).

### D. Barrel Export (`packages/engines/types/index.ts`)

- Xuất toàn bộ types tại một điểm duy nhất để các game import dễ dàng qua alias `@engines/types`.
