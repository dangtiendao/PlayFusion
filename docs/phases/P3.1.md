## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. Phong Bì Thông Điệp Chuẩn Hóa (`TransportEnvelope<T>`)

Mọi thông điệp trao đổi qua kênh Realtime Broadcast đều bắt buộc bọc trong phong bì `TransportEnvelope` phiên bản 1:

```typescript
export interface TransportEnvelope<T = unknown> {
  readonly v: 1; // Version phong bì (cố định = 1)
  readonly type: string; // Loại thông điệp ('ping', 'chat', 'move'...)
  readonly senderId: string; // UUID người gửi
  readonly sentAt: string; // ISO 8601 timestamp
  readonly payload: T; // Dữ liệu gói tin
}
```

### B. Quy Ước Đặt Tên Kênh & Xác Thực Mã Phòng

- **Quy ước tên kênh**: Luôn có tiền tố `match:{matchId}` (Ví dụ: `match:ROOM01`, `match:7b8e5c12-32a1-4091-86bf-6f5df8b8fa21`).
- **Validate định dạng**: `matchId` phải là UUID chuẩn (36 ký tự) hoặc Mã phòng 6 ký tự chữ in hoa/số `^[A-Z0-9]{6}$`.

### C. Giao Diện Lõi `MatchChannel` & Factory Function

```typescript
import { createMatchChannel, type MatchChannel } from '@/transport';

const channel = createMatchChannel(matchId, selfMember, {
  onMessage: (env) => { ... },
  onPresenceChange: (members) => { ... },
  onStatusChange: (status, detail) => { ... },
});

await channel.connect();
await channel.send('ping', { n: 1 });
const members = channel.getMembers(); // Sắp xếp tăng dần theo joinedAt
await channel.disconnect(); // Dọn dẹp sạch sẽ: untrack -> unsubscribe -> removeChannel
```

### D. React Hook Quản Lý Vòng Đời Màn Hình (`useMatchChannel`)

```typescript
import { useMatchChannel } from '@/transport';

const { status, members, send, reconnect } = useMatchChannel({
  matchId: activeRoomCode, // null -> tắt kết nối (idle)
  self: selfMember,
  onMessage: (envelope) => { ... },
  enabled: isScreenActive, // Màn hình chủ động bật/tắt
});
```

### E. Luật Tầng Kiến Trúc (`dependency-cruiser`)

- `src/transport/` là nơi **DUY NHẤT** được mở rộng để import `supabaseClient` từ `src/repositories/`.
- Toàn bộ các module khác (pages, games, components, stores, core) **CẤM** import `@supabase/supabase-js` hoặc import sâu vào file nội bộ trong `src/transport/` (chỉ được import qua `@/transport` hoặc `src/transport/index.ts`).

## 4. QUYẾT ĐỊNH THIẾT KẾ TRỌNG TÂM

| Quyết định                                                       | Lý do lựa chọn                                                                                                                                                                                                                                                  | Phương án đã loại bỏ & Rủi ro                                                                                           |
| :--------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------- |
| **Realtime Broadcast/Presence là "Dumb Pipe"**                   | Kênh Realtime Broadcast client-to-client không qua RLS bảng. Bất kỳ ai có mã phòng đều join được. Do đó transport chỉ làm ống truyền tin; mọi hành vi có giá trị pháp lý (nước đi, kết quả trận) **bắt buộc phải xác thực qua Edge Function Trọng Tài (P3.2)**. | _Tin tưởng nước đi gửi trực tiếp qua Broadcast_: Người chơi có thể hack client gửi nước đi sai luật hoặc tự khai thắng. |
| **Store in-memory, KHÔNG giữ Channel instance**                  | `transportStore` chỉ lưu trữ dữ liệu phẳng (`status`, `members`, `lastError`). Vòng đời kết nối do hook sở hữu.                                                                                                                                                 | _Lưu channel trong store_: Rò rỉ kết nối vĩnh viễn khi React hot-reload/refresh.                                        |
| **Chống Race Condition kép (`connectionIdRef` + `isCancelled`)** | Nếu unmount hoặc đổi trận xảy ra trong lúc `channel.connect()` đang pending, kết nối sẽ tự động bị ngắt ngay khi vừa resolve trong khối `.finally()`.                                                                                                           | _Chỉ dọn dẹp effect thông thường_: Kết nối mồ côi (orphan connection) tiếp tục sống ngầm sau unmount.                   |
| **Giữ callback `onMessage` qua Ref**                             | Tránh việc component cha re-render và truyền inline arrow function làm re-trigger `useEffect` gây disconnect/reconnect liên tục.                                                                                                                                | _Đưa `onMessage` vào dependency array_: Tốn tài nguyên và ngắt quãng trận đấu sau mỗi lần re-render.                    |
| **Chính sách Mobile `visibilitychange`**                         | Game đối kháng theo lượt (Caro), người chơi chuyển app trả lời tin nhắn trong vài giây là bình thường. Supabase WebSocket tự có timeout; client giữ kết nối để không bị đứt đoạn trải nghiệm.                                                                   | _Ngắt ngay khi hidden_: Người chơi bị văng khỏi phòng mỗi khi chuyển app đọc tin nhắn.                                  |
| **Khống chế `eventsPerSecond: 10`**                              | Game lượt phát sinh 0.2 - 1 msg/s. Ngưỡng 10 msg/s là dư dả và bảo vệ quota 2M messages/tháng của Free Tier khỏi vòng lặp vô tận.                                                                                                                               | _Không giới hạn_: Nguy cơ cháy hạn mức Free Tier chỉ sau một lỗi gửi tin lặp.                                           |

- **Kết quả 7 mục kiểm chứng**:
  - **(a) Presence**: 2 thiết bị (4G Mobile + WiFi Desktop) thấy nhau trong $\le 2\text{s}$.
  - **(b) Broadcast Ping**: 10/10 lượt ping truyền thành công 2 chiều, độ trễ 35-85ms.

  - **(d) Chuyển trang (Navigate Unmount)**: Bấm về Trang Chủ $\rightarrow$ Tự động ngắt kết nối sạch sẽ.
  - **(e) Background Mobile**: Tắt màn hình 10s $\rightarrow$ WebSocket duy trì ổn định.
  - **(f) Đối soát Quota Dashboard**: Khi thoát demo, Supabase Dashboard ghi nhận **0 kết nối Realtime**.
  - **(g) Duyệt trang khác**: Home, Profile, Caro offline duy trì **0 kết nối Realtime**.
