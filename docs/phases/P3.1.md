## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. React Hook `useMatchChannel` & Selectors

```typescript
import { useMatchChannel, useTransportStatus, useChannelMembers } from '@/transport';

function OnlineMatchRoom({ matchId, selfUser, onReceiveMove }) {
  // 1. Hook quản lý toàn bộ vòng đời kết nối
  const { status, members, send, reconnect } = useMatchChannel({
    matchId,
    self: {
      userId: selfUser.id,
      displayName: selfUser.displayName,
      joinedAt: new Date().toISOString(),
    },
    onMessage: (envelope) => {
      if (envelope.type === 'move') {
        onReceiveMove(envelope.payload);
      }
    },
    enabled: true, // Tắt/bật linh hoạt theo màn hình
  });

  // 2. Gửi thông điệp tới phòng
  const handleMakeMove = async (cellIndex: number) => {
    await send('move', { cell: cellIndex });
  };

  return (
    <div>
      <div>Trạng thái kết nối: {status}</div>
      <div>Đang trong phòng: {members.map((m) => m.displayName).join(', ')}</div>
      {status === 'error' && <button onClick={reconnect}>Kết nối lại</button>}
    </div>
  );
}
```

## 4. QUYẾT ĐỊNH THIẾT KẾ TRỌNG TÂM

| Quyết định                                             | Lý do lựa chọn                                                                                                     | Phương án đã loại bỏ & Rủi ro                                                                      |
| :----------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------- |
| **Store KHÔNG lưu tham chiếu instance Channel**        | Store chỉ phản chiếu trạng thái phẳng (`status`, `members`, `lastError`). Vòng đời channel do hook sở hữu.         | _Lưu channel trong store_: Gây rò rỉ kết nối treo vĩnh viễn khi hot-reload hoặc unmount.           |
| **`connectionIdRef` + `isCancelled` (Chống Race)**     | Triệt tiêu kết nối mồ côi nếu unmount xảy ra khi `channel.connect()` đang pending bất đồng bộ.                     | _Chỉ dùng cleanup thông thường_: `connect()` hoàn tất sau unmount sẽ tạo kết nối ma không thể dọn. |
| **Giữ `onMessage` qua `useRef`**                       | Ngăn chặn việc truyền inline callback arrow function làm re-trigger `useEffect` gây disconnect/reconnect liên tục. | _Đưa `onMessage` vào dependency array_: Gây reconnect sau mỗi lần render của component cha.        |
| **Chính sách Mobile `visibilitychange` (Giữ kết nối)** | Game đối kháng theo lượt (Caro), người chơi chuyển app vài giây là bình thường. Supabase WebSocket tự có timeout.  | _Ngắt ngay khi hidden_: Gây gián đoạn trải nghiệm ván đấu liên tục khi người chơi đọc thông báo.   |
| **Watchdog DEV-only**                                  | Báo động `console.error` khi có $>1$ hook active trong 1 tab giúp lập trình viên phát hiện sớm lỗi vòng đời.       | _Không giám sát_: Khó phát hiện bug rò rỉ kết nối trong môi trường phát triển local.               |
