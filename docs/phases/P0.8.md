## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. Chữ Ký `GameViewProps` Đầy Đủ Sau Mở Rộng (`src/games/types.ts`)

```typescript
export interface GameShellApi {
  readonly playSfx: (key: string, options?: { volume?: number }) => void;
  readonly hapticTap: () => void;
  readonly hapticSuccess: () => void;
  readonly hapticError: () => void;
}

export interface GameViewProps {
  /** Tờ khai năng lực của trò chơi (Bất biến từ P0.7a) */
  readonly definition: GameDefinition;
  /** Cờ báo trạng thái trò chơi đang tạm dừng do người dùng mở Pause Overlay */
  readonly isPaused?: boolean;
  /** Callback thông báo kết quả khi ván đấu kết thúc (MatchResultReport) */
  readonly onGameEnd?: (report: MatchResultReport) => void;
  /** Bộ API tiện ích do GameShell cung cấp (âm thanh, rung) */
  readonly shellApi?: GameShellApi;
}
```

### B. Quy Ước Bắt Buộc Dành Cho Mọi View Game (`src/games/<gameId>/View.tsx`)

1. **Tôn trọng `isPaused`**: Khi `isPaused === true`, View PHẢI disable mọi nút bấm đi nước và tạm dừng animation/timer nội bộ.
2. **Báo cáo kết quả ván đấu qua `onGameEnd`**: Khi `isTerminal` trả về true, View tạo `MatchResultReport` và gọi `onGameEnd(report)`.
3. **Phát âm thanh/rung qua `shellApi`**: Gọi `shellApi.playSfx('click')`, `shellApi.hapticTap()`, `shellApi.playSfx('success')` thay vì import trực tiếp từ `src/core` để đảm bảo View dễ test và mock.

### C. API Dịch Vụ Cốt Lõi (`src/core/`)

```typescript
// 1. Storage Manager (src/core/storage.ts)
storage.getItem<T>(key: string, fallback: T): T;
storage.setItem<T>(key: string, value: T): boolean;
storage.removeItem(key: string): void;
storage.clear(): void;

// 2. Audio Manager (src/core/audio.ts)
audioManager.playSfx(key: string, options?: { volume?: number }): void;
audioManager.unlock(): Promise<boolean>;
audioManager.loadSfx(key: string, url: string): Promise<void>;
audioManager.getState(): AudioContextState | 'unsupported';

// 3. Haptics Manager (src/core/haptics.ts)
vibrate(pattern: number | number[]): void;
hapticTap(): void;        // 15ms
hapticSuccess(): void;    // [20, 50, 40]
hapticError(): void;      // [40, 60, 40, 60, 40]
isHapticSupported(): boolean;

// 4. Input Normalizer (src/core/input.ts)
useUnifiedPress(onPress: () => void, options?: { threshold?: number; disabled?: boolean }): UnifiedPressHandlers;
useKeyboardShortcuts(shortcuts: Record<string, () => void>, options?: { enabled?: boolean }): void;
```

| Quyết định                                    | Lý do lựa chọn                                                                                                            | Phương án đã loại bỏ & Lý do loại                                                |

| **Web Audio API thay vì thẻ `<audio>`**       | Đạt độ trễ siêu thấp (<10ms), phát đa âm (polyphonic) nhiều hiệu ứng chồng nhau mượt mà khi đi cờ nhanh.                  | _Dùng thẻ `<audio>`_: Độ trễ cao (50-200ms) và bị nghẽn kênh khi phát liên tiếp. |

## 6. HƯỚNG DẪN VẬN HÀNH & KIỂM CHỨNG

### A. Kiểm Chứng Trên Máy Tính (Desktop Browser):

1. Chạy `npm run dev` hoặc mở bản deploy.
2. Vào `/settings`: Thử nghiệm các nút trong khu vực "Chẩn đoán thiết bị" (Âm click, Âm thắng, Đếm tap).
3. Vào `/game/dummy`:
   - Bấm nút **⏸️ Tạm dừng** $\rightarrow$ Pause Overlay hiển thị, các nút ghi điểm bị khóa.
   - Nhấn phím `Escape` $\rightarrow$ Resume ván đấu.
   - Bấm nút **← Rời trận** $\rightarrow$ ConfirmDialog cảnh báo xuất hiện $\rightarrow$ Bấm "Ở lại chơi tiếp".
   - Chơi hết 4 lượt $\rightarrow$ Console log `MatchResultReport` hợp lệ + SFX success phát ra $\rightarrow$ Bấm Back thoát thẳng về Sảnh mà không cần confirm.

### B. Kiểm Chứng Trên Điện Thoại Thật (Mobile):

1. Mở app trên điện thoại Android/iOS.
2. Vào `/game/dummy`:
   - **Xác nhận**: `BottomNav` ở đáy màn hình tự động biến mất, nhường trọn không gian cho GameShell.
   - Trên Android: Nút Fullscreen hoạt động $\rightarrow$ Ván cờ mở rộng toàn màn hình.
   - Trên iPhone: Nút Fullscreen tự động ẩn đi, layout hiển thị tràn viền chuẩn `safe-area`.
   - Bấm nút thoát $\rightarrow$ Quay về Trang chủ $\rightarrow$ `BottomNav` tự động hiển thị trở lại.
