## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. Path Aliases (TypeScript & Vite)

- `@/*`: Trỏ trực tiếp vào thư mục `src/*`.
- `@engines/*`: Trỏ trực tiếp vào thư mục `packages/engines/*`.

### B. Module Engine Mẫu: `packages/engines/_smoke.ts`

```typescript
export interface SmokeState {
  readonly score: number;
  readonly multiplier: number;
}

export function createInitialSmokeState(): SmokeState;
export function applySmokeScore(state: SmokeState, points: number): SmokeState;
```

_Ví dụ sử dụng:_

```typescript
import { createInitialSmokeState, applySmokeScore } from '@engines/_smoke';
const state = createInitialSmokeState(); // { score: 0, multiplier: 1 }
const nextState = applySmokeScore(state, 10); // { score: 10, multiplier: 1 }
```

```typescript
export interface AppConfig {
```

## 6. HƯỚNG DẪN VẬN HÀNH

### A. Yêu cầu môi trường

- **Node.js**: `v20.x` (LTS, khuyến nghị `v20.12.1+` theo `.nvmrc`).
- **npm**: `v9.x` hoặc `v10.x`.

### B. Danh mục lệnh thao tác hàng ngày

```bash
# 1. Chạy dev server cục bộ
npm run dev

# 2. Kiểm tra typecheck nghiêm ngặt
npm run typecheck

# 3. Kiểm tra và sửa lỗi lint
npm run lint
npm run lint:fix

# 4. Kiểm tra format
npm run format:check
npm run format

# 5. Chạy unit tests & Coverage
npm run test
npm run test:coverage

# 6. Build bundle production
npm run build
```

## 7. ĐẦU VÀO GỢI Ý CHO PHASE TIẾP THEO (P0.2 — CSDL Supabase, Migrations & RLS)

Phase `P0.2` cần nắm rõ các thông số kiến trúc đã chốt từ `P0.1`:

1. **Ranh giới thư mục**: Toàn bộ database types và Supabase client sẽ được tổ chức tại `src/repositories/` hoặc `src/types/database.ts` (không đặt trong `packages/engines/`).
2. **Dimension bất biến**: Bảng DB nào lưu trữ dữ liệu đa game bắt buộc phải có cột `game_id` làm dimension chính.
3. **Mô hình sổ cái**: Bảng `wallet_transactions` chỉ cho phép quyền `INSERT` (append-only ledger).
4. **Idempotency**: Mọi giao dịch ghi nhạy cảm bắt buộc có `idempotency_key`.
5. **Free-tier guard**: Bảng lưu trữ nước đi (`match_moves` hoặc `matches.state_history`) phải sẵn sàng giải pháp nén chuỗi/JSON để tối ưu giới hạn 500MB DB.
