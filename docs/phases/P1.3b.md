## 1. TÓM TẮT KẾT QUẢ

1. **Cơ chế 2 Chạm (2-Tap Confirmation) chống đánh nhầm ô trên mobile**:

   - Chạm lần 1 vào ô trống $\rightarrow$ Ô chuyển sang trạng thái **Preview** (quân mờ, viền nét đứt) + rung nhẹ `hapticTap()` + xuất hiện thanh xác nhận nổi với nút `[Đánh vào {tọa độ}]` (chiều cao $\ge 48\text{px}$, đáp ứng chuẩn Apple HIG / Material Design).
   - Chạm lần 2 vào **chính ô đang preview** $\rightarrow$ Xác nhận đánh ngay lập tức (Shortcut tiện lợi) + rung `hapticSuccess()` + phát âm thanh `click`.
   - Chạm sang ô trống khác $\rightarrow$ Chuyển preview sang ô mới.
   - Chạm vào nút Hủy (✕) hoặc bên ngoài $\rightarrow$ Xóa preview.
   - Chạm vào ô **đã có quân** $\rightarrow$ Rung cảnh báo `hapticError()` + nháy viền đỏ `errorFlashCell` trong 250ms + KHÔNG tạo preview.

2. **Cử chỉ Zoom-Pan-Pinch mượt mà**:

   - Sử dụng thư viện chuẩn `react-zoom-pan-pinch: ^3.6.1` bọc `BoardView`.
   - Cho phép phóng to từ 1x lên đến 3.2x, chụm 2 ngón (pinch), kéo lướt (pan).
   - Tích hợp nút nổi `"Về giữa"` (`recenter-btn`) ở góc trên phải khi `scale > 1.05`, bấm vào sẽ đưa bàn cờ về trạng thái 1x ban đầu.

3. **Thuật toán phân biệt Pan vs Tap (`classifyPointerGesture`)**:

   - Đặt ngưỡng dịch chuyển `PAN_DRAG_THRESHOLD_PX = 10px`.
   - Nếu người dùng di chuyển $> 10\text{px}$ khi chạm $\rightarrow$ Phân loại là hành vi kéo bàn cờ (Pan), tuyệt đối KHÔNG kích hoạt preview quân cờ.

4. **Trang demo kiểm chứng tương tác `BoardDemo.tsx` (`/dev/board-demo`)**:

   - Bàn 1 tích hợp `InteractiveBoard` cho phép tương tác trực tiếp: đổi lượt X/O cục bộ, zoom, pan, 2 chạm, haptic và recenter.

5. **Kiểm thử tự động**:
   - 31 test files (228/228 tests) pass 100%.
   - Đạt độ phủ coverage cao trên toàn bộ module tương tác Caro.

```typescript
// src/games/caro/components/InteractiveBoard.tsx
export interface InteractiveBoardProps {
  /** Mảng 1 chiều trạng thái bàn cờ */
  readonly board: readonly number[];
  /** Kích thước cạnh bàn cờ (ví dụ: 15 cho bàn 15x15) */
  readonly boardSize: number;
  /** Index ô của nước đi cuối cùng (hoặc null) */
  readonly lastMove: number | null;
  /** Danh sách index các ô thuộc chuỗi thắng 5 quân (hoặc null) */
  readonly winLine: readonly number[] | null;
  /** Vô hiệu hóa tương tác đánh cờ (khi AI đang tính, paused, kết thúc ván) */
  readonly disabled?: boolean;
  /** Người chơi hiện tại (0: X, 1: O) để render preview */
  readonly currentPlayer?: number;
  /** Hàm kiểm tra ô có thể đánh được hay không (mặc định: board[index] === -1) */
  readonly isCellPlayable?: (index: number) => boolean;
  /** Callback kích hoạt khi nước đi được xác nhận */
  readonly onMoveConfirmed: (index: number) => void;
  /** Callback phát hiệu ứng âm thanh */
  readonly onSfx?: (name: 'click' | 'success' | 'error') => void;
  /** ClassName tùy biến cho container bao bọc bên ngoài */
  readonly className?: string;
}

export const InteractiveBoard: React.FC<InteractiveBoardProps>;
```

## 3. HƯỚNG DẪN KIỂM CHỨNG BẰNG THIẾT BỊ

1. **Khởi động Dev Server**:
   ```bash
   npm run dev
   ```
2. **Truy cập trang demo**: `http://localhost:5173/dev/board-demo`
3. **Thử nghiệm các ca cử chỉ**:
   - **Trên Mobile**: Dùng 2 ngón phóng to bàn cờ $\rightarrow$ Kéo lướt bàn cờ (không bị dính preview) $\rightarrow$ Chạm nhẹ vào ô trống (thấy rung nhẹ + preview + nút "Đánh vào H8") $\rightarrow$ Chạm tiếp vào chính ô đó (quân cờ được đánh xuống + rung success + đổi lượt sang quân O).
   - **Thử ô đã có quân**: Chạm vào ô đã có quân cờ $\rightarrow$ Cảm nhận rung error + viền ô nhấp nháy đỏ 250ms.
   - **Nút Về giữa**: Khi đang phóng to bàn cờ, bấm nút "Về giữa" ở góc phải để reset tỷ lệ phóng về 1x.
