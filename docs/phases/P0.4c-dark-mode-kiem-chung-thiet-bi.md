## 1. Các thành phần đã triển khai

### A. Hook Quản lý Theme (`src/core/useTheme.ts`)

- **Tự động nhận diện theme hệ điều hành**: Khởi tạo bằng `window.matchMedia('(prefers-color-scheme: dark)')`.
- **Lắng nghe thay đổi theme của OS Real-time**: Lắng nghe sự kiện `change` trên MediaQueryList $\rightarrow$ tự động chuyển theme khi người dùng đổi cài đặt trên điện thoại/máy tính (NẾU chưa bấm toggle thủ công trong phiên).
- **Toggle thủ công**: Hàm `toggleTheme()` thêm/bỏ class `dark` trên `document.documentElement` (`<html>`).
- **Đồng bộ Thẻ Meta `theme-color`**: Đổi màu thanh trạng thái trình duyệt Safari/Chrome (`#f8fafc` ở Light mode $\leftrightarrow$ `#0f172a` ở Dark mode).
- **Ghi chú kiến trúc**: Trạng thái lưu in-memory trong phiên, persistence vào `localStorage` sẽ được chuyển sang Phase P0.8 (`src/core/storage.ts`).

## 3. Hướng dẫn kiểm tra DoD từng mục trên trình duyệt

### A. Kiểm tra tự động đổi Theme theo OS:

1. Mở DevTools (`F12`) $\rightarrow$ Mở menu **Rendering** (nhấn `Ctrl + Shift + P` $\rightarrow$ gõ `Rendering`).
2. Cuộn tới mục **Emulate CSS media feature prefers-color-scheme**:
   - Chọn `prefers-color-scheme: dark` $\rightarrow$ App tự động chuyển nền tối than chì.
   - Chọn `prefers-color-scheme: light` $\rightarrow$ App tự động chuyển nền sáng sạch sẽ.

### B. Kiểm tra Thẻ `<meta name="theme-color">`:

1. Mở tab **Elements** trong DevTools $\rightarrow$ Xem thẻ `<head>`.
2. Bấm nút ☀️ / 🌙 trên Header:
   - **Xác nhận**: Giá trị `content` của thẻ `meta[name="theme-color"]` đổi ngay lập tức giữa `#f8fafc` và `#0f172a`.
