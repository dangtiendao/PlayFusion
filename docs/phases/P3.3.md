## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. TypeScript Interface `roomRepository` (`src/repositories/roomRepository.ts`)

```typescript
export interface RoomDto {
  readonly code: string;
  readonly expiresAt: string;
}

export interface JoinRoomResultDto {
  readonly matchId: string;
  readonly mySeat: number;
  readonly gameId: string;
}

export interface RoomStatusDto {
  readonly status: 'waiting' | 'matched' | 'cancelled' | 'expired';
  readonly matchId: string | null;
  readonly gameId: string;
  readonly mySeat: number;
}

export interface RoomInfoDto {
  readonly code: string;
  readonly hostId: string;
  readonly gameId: string;
  readonly status: string;
  readonly expiresAt: string;
}

export const roomRepository = {
  createRoom(gameId: string): Promise<RoomDto>;
  joinRoom(code: string): Promise<JoinRoomResultDto>;
  cancelRoom(code: string): Promise<boolean>;
  getRoomStatus(code: string): Promise<RoomStatusDto>;
  getRoomInfo(code: string): Promise<RoomInfoDto | null>;
  notifyRoomMatched(code: string, matchId: string, hostSeat: number): Promise<void>;
};
```

## 4. QUYẾT ĐỊNH THIẾT KẾ TRONG PHASE

| Quyết định                                                                      | Lý do lựa chọn                                                                                                                                                                                                        | Phương án đã loại bỏ & Rủi ro                                                                                    |
| :------------------------------------------------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------- |
| **Bảng chữ 32 ký tự an toàn**                                                   | Bỏ `O/0` và `I/1` giúp người chơi đọc mã cho nhau qua điện thoại/tin nhắn không bị nhầm lẫn. Không gian $32^6 \approx 1.07$ tỷ mã đảm bảo không bao giờ cạn mã.                                                       | _Dùng toàn bộ [A-Z0-9] (36 ký tự)_: Dễ nhầm giữa chữ O và số 0, chữ I và số 1.                                   |
| **Atomic Optimistic State Transition khi Join**                                 | Câu lệnh `UPDATE rooms SET status='matched' WHERE code=? AND status='waiting'` là nguyên tử (Atomic). Nếu có 2 người cùng bấm vào 1 phòng, đúng 1 người cập nhật được dòng, người kia nhận `ROOM_TAKEN` ngay lập tức. | _Đọc SELECT rồi mới UPDATE_: Dễ bị Race Condition khi 2 người cùng đọc thấy 'waiting' và cùng gửi request join.  |
| **2 Đường phát hiện ghép thành công cho Host (Realtime + Polling Fallback 5s)** | Broadcast Realtime giúp điều hướng tức thì (<50ms). Fallback Polling 5s bảo đảm nếu mạng 3G/4G chập chờn rớt gói tin broadcast thì Host vẫn tự động vào ván cờ.                                                       | _Chỉ dùng Realtime_: Nếu Host bị disconnect tạm thời đúng lúc Guest join thì Host sẽ bị kẹt vĩnh viễn ở màn chờ. |
| **Web Share API (`navigator.share`) + Fallback Copy Link**                      | Chia sẻ 1 chạm mở trực tiếp native share sheet của iOS/Android/Zalo. Nếu trình duyệt không hỗ trợ thì fallback sang copy link vào clipboard.                                                                          | _Chỉ hiển thị link dạng text_: Trải nghiệm trên mobile kém, người dùng phải bôi đen sao chép thủ công.           |
