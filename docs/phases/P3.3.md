## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. DDL Bảng `public.rooms`

```sql
CREATE TABLE public.rooms (
  code text PRIMARY KEY CHECK (code ~ '^[A-Z0-9]{6}$'),
  host_id uuid NOT NULL REFERENCES public.profiles(user_id) ON DELETE CASCADE,
  game_id text NOT NULL REFERENCES public.games(id),
  status text NOT NULL DEFAULT 'waiting'
    CHECK (status IN ('waiting', 'matched', 'cancelled', 'expired')),
  match_id uuid NULL REFERENCES public.matches(id) ON DELETE SET NULL,
  created_at timestamptz NOT NULL DEFAULT now(),
  expires_at timestamptz NOT NULL DEFAULT (now() + interval '30 minutes'),
  matched_at timestamptz NULL,
  CONSTRAINT chk_rooms_matched_has_match_id CHECK ((status = 'matched') = (match_id IS NOT NULL))
);

-- Partial Index: 1 Host chỉ có tối đa 1 phòng 'waiting'
CREATE UNIQUE INDEX idx_rooms_host_waiting ON public.rooms(host_id) WHERE status = 'waiting';
CREATE INDEX idx_rooms_game_status ON public.rooms(game_id, status);
```

### B. Chữ Ký 4 RPCs `SECURITY DEFINER` (search_path = '')

#### 1. `public.create_room(p_game_id text) RETURNS TABLE(code text, expires_at timestamptz)`

- **Vai trò**: Tạo phòng đấu mới với mã 6 ký tự an toàn.
- **Hành vi**: Tự động hủy phòng `waiting` cũ của host (nếu có), sinh mã ngẫu nhiên 32 ký tự, đặt TTL 30 phút.

#### 2. `public.join_room(p_code text) RETURNS TABLE(match_id uuid, my_seat smallint, game_id text)`

- **Vai trò**: Khách vào phòng đấu và bắt đầu ván cờ.
- **Hành vi**: Atomic update `waiting` $\rightarrow$ `matched` (chống đua), chia ghế 50/50 ngẫu nhiên, tự tạo `matches` (`mode: 'online_1v1'`) + `match_participants` cho cả 2 người.

#### 3. `public.cancel_room(p_code text) RETURNS boolean`

- **Vai trò**: Host chủ động hủy phòng chờ khi chưa có người vào.

#### 4. `public.get_my_room_status(p_code text) RETURNS TABLE(status text, match_id uuid, game_id text, my_seat smallint)`

- **Vai trò**: Fallback polling cho Host khi đang ở màn hình chờ phòng (phòng hờ mất gói tin Realtime).

## 4. QUYẾT ĐỊNH THIẾT KẾ TRONG PHASE

| Quyết định                                         | Lý do lựa chọn                                                                                                                                                                                                        | Phương án đã loại bỏ & Rủi ro                                                                                   |
| :------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------- |
| **Bảng chữ 32 ký tự an toàn**                      | Bỏ `O/0` và `I/1` giúp người chơi đọc mã cho nhau qua điện thoại/tin nhắn không bị nhầm lẫn. Không gian $32^6 \approx 1.07$ tỷ mã đảm bảo không bao giờ cạn mã.                                                       | _Dùng toàn bộ [A-Z0-9] (36 ký tự)_: Dễ nhầm giữa chữ O và số 0, chữ I và số 1.                                  |
| **Atomic Optimistic State Transition khi Join**    | Câu lệnh `UPDATE rooms SET status='matched' WHERE code=? AND status='waiting'` là nguyên tử (Atomic). Nếu có 2 người cùng bấm vào 1 phòng, đúng 1 người cập nhật được dòng, người kia nhận `ROOM_TAKEN` ngay lập tức. | _Đọc SELECT rồi mới UPDATE_: Dễ bị Race Condition khi 2 người cùng đọc thấy 'waiting' và cùng gửi request join. |
| **Tự động hủy phòng waiting cũ khi tạo phòng mới** | 1 người chơi không thể ngồi chờ ở 2 phòng cùng lúc. Thay vì báo lỗi bắt người dùng hủy tay, server tự chuyển phòng cũ sang `cancelled`.                                                                               | _Chặn tạo phòng mới khi đã có phòng cũ_: Gây khó chịu cho UX khi người dùng quên mã phòng cũ.                   |
| **Chia ghế ngẫu nhiên 50/50 từ Server**            | Đảm bảo tính công bằng thể thao điện tử — không ai được ưu tiên luôn cầm quân đi trước (Seat 0).                                                                                                                      | _Mặc định Host luôn là Seat 0_: Gây bất công cho người đi tìm phòng.                                            |
