## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. Tầng Repositories (Domain Types & Methods)

```typescript
// 1. Ghi nhận ván đấu offline lên Cloud
import { recordOfflineMatch } from '@/repositories/matchRepository';
import type { RecordOfflineMatchParams } from '@/repositories/types';

await recordOfflineMatch({
  matchId: '11111111-2222-3333-4444-555555555555',
  gameId: 'caro',
  mode: 'vs_ai',
  startedAt: new Date(),
  durationMs: 120000,
  endReason: 'five_in_a_row',
  engineOptions: '{"boardSize":15}',
  finalState: '...',
  moves: '112,97,113',
  participants: [
    { seatIndex: 0, isBot: false, result: 'win' },
    { seatIndex: 1, isBot: true, botLevel: 'medium', result: 'loss' },
  ],
});

// 2. Đọc danh mục và mùa giải
import { getGames, getActiveSeason } from '@/repositories/catalogRepository';
const games = await getGames();
const season = await getActiveSeason();

// 3. Đọc lịch sử ván đấu & Chi tiết ván
import { getMyRecentMatches, getMatchById } from '@/repositories/matchRepository';
const recentMatches = await getMyRecentMatches('caro', 20);
const matchDetail = await getMatchById('match-uuid');

// 4. Đọc điểm xếp hạng cá nhân
import { getMyRatings, getRating } from '@/repositories/ratingRepository';
const ratings = await getMyRatings(1);
```

## 4. QUYẾT ĐỊNH THIẾT KẾ TRONG PHASE

| Quyết định                                             | Lý do                                                                                                                                                                  | Phương án đã loại                                                                                   |
| :----------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------- |
| **Client sinh `matchId` lúc ván bắt đầu**              | Idempotency Key tự nhiên. Khi Outbox retry nhiều lần, server phát hiện trùng `match_id` và `RETURN v_match_id` an toàn, không tạo bản ghi rác.                         | Server tự sinh UUID khi nhận request $\rightarrow$ Rủi ro tạo bản ghi trùng lặp khi mạng lag/retry. |
| **Server TỰ GÁN `user_id = auth.uid()` trong RPC**     | Khóa chặt mạo danh. Client không truyền `user_id`; Stored Procedure tự gán định danh của phiên xác thực hiện tại cho ghế người chơi.                                   | Tin cậy `user_id` từ client $\rightarrow$ Lỗ hổng bảo mật nghiêm trọng (mạo danh ghi điểm).         |
| **Phân loại lỗi `RepoError` ('RETRYABLE' vs 'FATAL')** | Lỗi FATAL (sai schema, cấm quyền) không thể tự hết $\rightarrow$ gỡ bỏ ngay để không tắc queue; lỗi RETRYABLE (mất mạng) $\rightarrow$ giữ lại và tạm dừng đợi online. | Retry vô tận mọi loại lỗi $\rightarrow$ Làm kẹt hàng đợi vĩnh viễn nếu payload hỏng.                |
| **Trần dung lượng 50 items FIFO**                      | Khống chế dung lượng Local Storage và dọn dẹp item cũ tự động khi chơi offline dài ngày.                                                                               | Lưu không giới hạn $\rightarrow$ Tràn Quota Storage hoặc làm chậm tiến trình xử lý.                 |

  ```sql
  SELECT
    p.proname,
    p.prosecdef AS is_security_definer,
    p.proconfig AS search_path_config,
    pg_get_function_arguments(p.oid) AS arguments,
    pg_get_function_result(p.oid) AS return_type,
    p.proacl AS access_control_list
  FROM pg_proc p
  JOIN pg_namespace n ON p.pronamespace = n.oid
  WHERE n.nspname = 'public' AND p.proname = 'record_offline_match';
  ```

## 7. ĐẦU VÀO GỢI Ý CHO PHASE KẾ TIẾP [P2.6: HỒ SƠ & THỐNG KÊ ONLINE]

1. **Dữ liệu trận đấu sẵn có trên Cloud**: Bảng `matches` và `match_participants` đã có dữ liệu trận offline đồng bộ lên (`game_mode = 'vs_ai' | 'local_pvp'`, `is_ranked = false`).

   - `getMyRecentMatches(gameId, limit)` $\rightarrow$ Hiển thị lịch sử ván đấu trực tuyến trên trang Profile.
   - `getMyRatings(seasonId)` và `getRating(userId, gameId, seasonId)` $\rightarrow$ Hiển thị điểm xếp hạng khi mùa giải mở.
3. **Quy ước hiển thị thống kê**:
   - Tỷ lệ thắng (Win Rate) ẩn nếu người chơi đấu dưới 10 trận.
   - Giao diện Profile đọc danh sách trò chơi linh hoạt từ Registry (`getAllGames()`), không hardcode tên game cụ thể.
