# Nghiệm thu Phase P0.8b: audio.ts + haptics.ts + Chuẩn Hóa Input

- **Mã phase**: `P0.8b`
- **Mục tiêu**: Xây dựng 3 module dịch vụ phần cứng & trình duyệt cốt lõi: Âm thanh Web Audio API (`audio.ts`), Rung phản hồi xúc giác (`haptics.ts`), và Chuẩn hóa đầu vào cảm ứng/bàn phím (`input.ts`), kèm công cụ chẩn đoán phần cứng trên trang Cài đặt.
- **Trạng thái**: ✅ **HOÀN THÀNH 100% (DoD Approved)**

## 1. Các thành phần đã triển khai

### A. Module Hiệu Ứng Âm Thanh Web Audio API (`src/core/audio.ts`)

- **Web Audio API**: Sử dụng `AudioContext` và `AudioBufferSourceNode` (độ trễ <10ms, polyphonic phát nhiều âm thanh chồng nhau mượt mà), không dùng thẻ `<audio>`.
- **Autoplay Unlock**: Tự động đăng ký one-time listener `pointerdown`/`keydown` toàn cục để mở khóa `AudioContext` sau cử chỉ chạm đầu tiên của người dùng.
- **Tuân thủ Muted**: Kiểm tra trực tiếp `useSettingsStore.getState().soundEnabled` tại thời điểm gọi `playSfx`.
- **File SFX siêu nhẹ**: Tạo 3 file WAV chuẩn 16-bit PCM Mono qua script `scripts/generate-sfx.js` đặt tại `public/sfx/` (`click.wav` 4.4KB, `success.wav` 19.4KB, `error.wav` 15.9KB — tổng dung lượng < 40KB).

### B. Module Rung Phản Hồi Xúc Giác (`src/core/haptics.ts`)

- **Feature Detection**: Kiểm tra `'vibrate' in navigator` an toàn. Trên thiết bị không hỗ trợ (như iOS Safari), các hàm rung tự động suy thoái thành no-op không gây lỗi.
- **Tuân thủ Cài đặt**: Kiểm tra `useSettingsStore.getState().hapticEnabled`.
- **Presets Ngữ Nghĩa**:
  - `hapticTap()`: Rung nhẹ 15ms khi chạm/đặt cờ.
  - `hapticSuccess()`: Mô thức nhịp điệu `[20, 50, 40]` khi thắng ván.
  - `hapticError()`: Mô thức cảnh báo `[40, 60, 40, 60, 40]` khi đi sai nước/thua ván.

### C. Module Chuẩn Hóa Đầu Vào (`src/core/input.ts`)

- **Hook `useUnifiedPress`**:
  - Sử dụng chuẩn W3C Pointer Events (`pointerdown`, `pointerup`) giải quyết triệt để vấn đề double-fire trên các thiết bị cảm ứng lai (laptop màn hình cảm ứng, iPad có trackpad).
  - Phân biệt Tap vs Drag/Scroll: Ngưỡng di chuyển 10px — nếu người dùng vuốt/kéo quá 10px thì hủy tap, tránh kích hoạt nhầm khi cuộn trang.
  - Thiết lập `touchAction: 'manipulation'` loại bỏ độ trễ 300ms double-tap.
- **Hook `useKeyboardShortcuts`**:
  - Đăng ký phím tắt toàn cục, tự động lọc bỏ phím lặp `event.repeat` khi đè giữ phím và bỏ qua khi đang gõ trong form input/textarea.

### D. Khu Vực Chẩn Đoán Thiết Bị (`src/pages/SettingsPage.tsx`)

- Hiển thị trực quan trạng thái `AudioContext` (`running` / `suspended`), trạng thái hỗ trợ Vibration API.
- Cung cấp các nút bấm kiểm tra trực tiếp âm thanh, rung và bộ đếm Unified Press.

### E. Bộ Unit Tests (`src/core/*.test.ts`)

- 17 test cases bao phủ đầy đủ 3 module mới (`audio.test.ts`: 5 tests, `haptics.test.ts`: 5 tests, `input.test.ts`: 7 tests), nâng tổng số test của dự án lên **69/69 tests pass 100%**.

## 3. Hướng dẫn thử nghiệm kiểm chứng trên thiết bị

1. **Kiểm tra Web Audio Autoplay Unlock & SFX**:
   - Mở ứng dụng trên điện thoại $\rightarrow$ Vào `/settings` $\rightarrow$ Chạm bất kỳ đâu trên màn hình $\rightarrow$ Trạng thái `AudioContext` hiển thị `running` màu xanh.
   - Bấm **"🔊 Thử Âm Click"** và **"🎉 Thử Âm Thắng"** $\rightarrow$ Loa phát âm thanh với độ trễ tức thì (<10ms).
2. **Kiểm tra Rung Haptics & Tương thích iOS**:
   - Trên máy Android: Bấm **"📳 Thử Rung Nhẹ"** $\rightarrow$ Điện thoại rung phản hồi 15ms.
   - Trên iPhone (iOS Safari): Trạng thái hiển thị `Không hỗ trợ (iOS)`, bấm nút thử hoàn toàn không gây crash app.
3. **Kiểm tra Toggle Cài Đặt**:
   - Gạt tắt Toggle "Hiệu ứng Âm thanh" và "Rung phản hồi" $\rightarrow$ Bấm lại các nút thử $\rightarrow$ Thiết bị im lặng hoàn toàn.
