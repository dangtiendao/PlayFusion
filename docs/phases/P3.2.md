## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. Quy Ước Response JSON Bắt Buộc Cho Toàn Bộ Edge Functions

Mọi Edge Functions từ Phase P3.2 trở đi đều trả về cấu trúc JSON đồng nhất:

- **Thành công (HTTP 200)**:
  ```json
  {
    "ok": true,
    "data": { ... }
  }
  ```
- **Thất bại (HTTP 400 / 401 / 403 / 500)**:
  ```json
  {
    "ok": false,
    "error": {
      "code": "ERROR_CODE_UPPERCASE",
      "message": "Thông điệp mô tả lỗi chi tiết bằng tiếng Việt."
    }
  }
  ```

### B. Helper Xuất Khẩu Từ `_shared/`

```typescript
import { handleCors, corsHeaders } from '../_shared/cors.ts';
import { successResponse, errorResponse, type ApiResponse } from '../_shared/response.ts';
import { createAdminClient, getUserFromRequest } from '../_shared/supabaseAdmin.ts';
```

### C. Import Game Engine Trong Deno

Edge Functions import trực tiếp từ thư mục `packages/engines/`:

```typescript
import { caroEngine } from '../../../packages/engines/caro/engine.ts';
import { CaroMovesCodec } from '../../../packages/engines/caro/moves-codec.ts';
import { DEFAULT_CARO_OPTIONS } from '../../../packages/engines/caro/types.ts';
```

   ```bash
   npx supabase login
   ```
2. **Liên kết Project DEV**:
   ```bash
   npx supabase link --project-ref <DEV_PROJECT_REF>
   ```
3. **Deploy Function**:
   ```bash
   npx supabase functions deploy hello-referee
   ```
4. **Kiểm tra curl**:
   - **Test 1 (Không JWT -> 401)**:
     ```bash
     curl -i -X POST https://<DEV_REF>.supabase.co/functions/v1/hello-referee
     ```
     _Kỳ vọng_: HTTP 401 với `{ "ok": false, "error": { "code": "UNAUTHORIZED", ... } }`.
   - **Test 2 (Có Bearer JWT -> 200)**:
     ```bash
     curl -i -X POST https://<DEV_REF>.supabase.co/functions/v1/hello-referee \
       -H "Authorization: Bearer <USER_JWT_TOKEN>"
     ```
     _Kỳ vọng_: HTTP 200 với `{ "ok": true, "data": { "userId": "...", "moveCount": 1, "deno": "..." } }`.

## 7. ĐẦU VÀO GỢI Ý CHO PHASE KẾ TIẾP [P3.2B: LIVE MATCH STATE SCHEMA & RLS]

1. **Hạ tầng Deno & Functions đã sẵn sàng**: `supabase/functions/_shared/` đã có đầy đủ CORS, JSON response chuẩn và Admin client.
2. **Nhiệm vụ trọng tâm Phase P3.2b**:
   - Thiết kế migration SQL `0012_live_match_state.sql`:
     - Bổ sung cấu trúc lưu trữ `current_state` (chuỗi serialize nén RLE v1), `move_count`, `current_turn_seat`, `version` (optimistic locking) vào bảng `matches` (hoặc bảng phụ trợ `match_states`).
     - Thiết lập RLS: Client chỉ được `SELECT` trạng thái ván đấu mà mình tham gia, tuyệt đối **CẤM `UPDATE` trực tiếp từ client** (chỉ cho phép Service Role của Edge Function cập nhật sau khi Trọng tài thẩm định).
