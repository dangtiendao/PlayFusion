## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. Endpoint Edge Function Trọng Tài: `POST /functions/v1/referee`

Yêu cầu Header: `Authorization: Bearer <USER_JWT_TOKEN>`.

#### 1. Action `init` (Khởi tạo thế cờ)

- **Request Body**:
  ```json
  {
    "action": "init",
    "matchId": "uuid-cua-tran-dau"
  }
  ```
- **Response Thành Công (HTTP 200)**:
  ```json
  {
    "ok": true,
    "data": {
      "stateSerialized": "v1:15:5:0:1:0:0:-1:225.",
      "moveIndex": 0,
      "currentSeat": 0,
      "movesSerialized": ""
    }
  }
  ```

#### 2. Action `move` (Thẩm định nước đi)

- **Request Body**:
  ```json
  {
    "action": "move",
    "matchId": "uuid-cua-tran-dau",
    "moveSerialized": "112",
    "expectedMoveIndex": 0
  }
  ```
- **Response Nước Đi Hợp Lệ (HTTP 200)**:
  ```json
  {
    "ok": true,
    "data": {
      "moveIndex": 1,
      "moveSerialized": "112",
      "currentSeat": 1,
      "stateSerialized": "v1:15:5:0:1:1:1:112:112.x112.",
      "terminal": null
    }
  }
  ```
- **Response Nước Đi Trùng Lặp (Idempotent Duplicate - HTTP 200)**:
  ```json
  {
    "ok": true,
    "data": {
      "duplicate": true,
      "stateSerialized": "...",
      "moveIndex": 1,
      "currentSeat": 1
    }
  }
  ```
- **Response Lỗi Thẩm Định Chuẩn Hóa**:
  - `403 NOT_PARTICIPANT`: Không phải người chơi trong phòng.
  - `403 WRONG_TURN`: Chưa đến lượt đi.
  - `404 MATCH_NOT_FOUND`: Không tìm thấy ván đấu hoặc chưa khởi tạo.
  - `409 MATCH_ENDED`: Ván đấu đã kết thúc.
  - `409 STALE_CLIENT`: Client bị lệch nhịp hoặc thua đua khóa lạc quan.
  - `422 ILLEGAL_MOVE`: Nước đi sai luật cờ (ô đã có quân).

### B. Broadcast Envelope Phía Server (`TransportEnvelope v1`)

- **Khởi tạo**: `{ "v": 1, "type": "match_ready", "senderId": "server", "payload": { "matchId", "moveIndex": 0, "currentSeat": 0 } }`
- **Nước đi chấp thuận**: `{ "v": 1, "type": "move_accepted", "senderId": "server", "payload": { "matchId", "moveIndex", "moveSerialized", "currentSeat", "terminal" } }`

## 4. QUYẾT ĐỊNH THIẾT KẾ TRONG PHASE

| Quyết định                                           | Lý do lựa chọn                                                                                                                                              | Phương án đã loại bỏ & Rủi ro                                                                                                   |
| :--------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------ |
| **Chuỗi thẩm định a $\rightarrow$ f**                | Chuẩn hóa thứ tự kiểm tra từ rẻ tiền (auth, participant, turn) đến đắt tiền (engine applyMove) giúp giảm tải CPU server.                                    | _Gọi engine ngay lập tức_: Lãng phí tài nguyên CPU cho các request gửi sai lượt hoặc gửi bởi người ngoài.                       |
| **Khóa Lạc Quan `move_index`**                       | Ràng buộc `WHERE move_index = expectedMoveIndex` đảm bảo mỗi nước đi được áp dụng tuần tự nghiêm ngặt, chống race condition khi 2 bên bấm cờ cùng lúc.      | _Khóa bi quan (Pessimistic Lock / SELECT FOR UPDATE)_: Giữ transaction dài làm chậm latency và dễ gây deadlock trên serverless. |
| **Phát sóng Broadcast sau khi ghi DB**               | Chỉ phát sóng thông điệp khi DB đã ghi nhận thành công, bảo đảm cả 2 client luôn đồng bộ với trạng thái đã lưu trữ trên server.                             | _Broadcast trước khi ghi DB_: Nếu DB ghi lỗi, client sẽ rơi vào trạng thái ảo (ghost state).                                    |
| **Xóa `match_live_state` khi ván kết thúc**          | Khi có người thắng/hòa, kết quả được finalize vào bảng `matches` (`final_state`, `moves`). Xóa live_state giúp tiết kiệm dung lượng Free Tier.              | _Giữ live state vĩnh viễn_: Phình bảng `match_live_state` theo thời gian.                                                       |
| **Log 1 dòng JSON có cấu trúc (Structured Logging)** | In đúng 1 dòng JSON chứa mã định danh, action, outcome và thời gian ms; **tuyệt đối không log chuỗi state bàn cờ** để tránh rác log và bảo mật chiến thuật. | _Console.log toàn bộ state_: Lộ chiến thuật và làm đầy hạn mức log của Supabase.                                                |
