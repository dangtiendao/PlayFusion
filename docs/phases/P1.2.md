## 1. TÓM TẮT

1. Triển khai hoàn chỉnh "bộ não" AI Cờ Caro thuần TypeScript độc lập (`packages/engines/caro/ai/`) với bảng điểm lũy tiến `PATTERN_SCORES`, hàm lượng giá toàn cục `evaluateBoard` ($\mathcal{O}(N)$ khử trùng lặp) và hàm sinh nước ứng viên `generateCandidates` kết hợp Move Ordering.

3. Thiết lập 3 mức độ thông minh: **Easy** (depth 1, nhiễu 30%, quên chặn 30%), **Medium** (depth 2, không nhiễu, luôn chặn), **Hard** (depth 4, budget 1500ms, iterative deepening, phát hiện bẫy đôi).

5. Tạo trang kiểm chứng độc lập `/dev/ai-demo` với spinner 60 FPS quay mượt mà không bị khựng giật trong suốt quá trình AI Hard tính toán. Toàn bộ 28 test files (202/202 tests) pass sạch 100%.

## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS CHO P1.3 VIEW & P1.4)

### A. React Hook `useCaroAi` (`src/games/caro/useCaroAi.ts`)

```typescript
export interface UseCaroAiOptions {
  readonly minDelayMs?: number; // Mặc định 500ms
  readonly workerFactory?: () => Worker;
}

export interface UseCaroAiReturn {
  requestMove(state: CaroState, config: AiConfig): Promise<CaroMove>;
  isThinking: boolean;
  cancel(): void;
}

export function useCaroAi(options?: UseCaroAiOptions): UseCaroAiReturn;
```

**Ví dụ sử dụng trong Caro View (P1.3)**:

```tsx
const { requestMove, isThinking, cancel } = useCaroAi({ minDelayMs: 500 });

// Khi đến lượt AI:
useEffect(() => {
  if (isAiTurn && !state.isTerminal) {
    requestMove(state, { level: 'hard', seed: currentMatchSeed })
      .then((bestMove) => {
        applyMoveToBoard(bestMove);
      })
      .catch((err) => {
        if (err.message !== 'CARO_AI_REQUEST_CANCELLED') {
          console.error('Lỗi tính nước đi AI:', err);
        }
      });
  }
}, [isAiTurn, state]);
```

### B. Quy ước truyền State vào Worker

- Trạng thái bàn cờ bắt buộc phải truyền dưới dạng chuỗi JSON `caroEngine.serialize(state)`.
- Lý do: Tận dụng cơ chế validation của `deserialize`, tránh structured-clone lỗi object, đồng nhất 100% với giao thức Edge Function trọng tài ở **P3.2**.

### C. Giao diện Cấu hình 3 Mức Độ Khó (`levels.ts`)

```typescript
export type AiLevel = 'easy' | 'medium' | 'hard';

export interface AiConfig {
  readonly level: AiLevel;

  readonly disablePruning?: boolean;
}

export interface AiResult {
  readonly move: CaroMove;
  readonly score: number;
  readonly depth: number;
  readonly nodes: number;
  readonly elapsedMs: number;
}
```
