## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS CHO P1.3 & P1.4)

### A. React Hook `useCaroAi` (`src/games/caro/useCaroAi.ts`)

```typescript
export interface UseCaroAiOptions {
  readonly minDelayMs?: number; // Mặc định 500ms
  readonly workerFactory?: () => Worker;
}

export interface UseCaroAiReturn {
  requestMove(state: CaroState, config: AiConfig): Promise<CaroMove>;
  isThinking: boolean;
  cancel(): void;
}

export function useCaroAi(options?: UseCaroAiOptions): UseCaroAiReturn;
```

**Ví dụ gọi trong Caro View (P1.3)**:

```tsx
import { useCaroAi } from '@/games/caro';

const { requestMove, isThinking, cancel } = useCaroAi({ minDelayMs: 500 });

// Khi đến lượt AI đi:
const handleAiTurn = async () => {
  try {
    const bestMove = await requestMove(state, { level: 'hard', seed: currentMatchSeed });
    dispatchMove(bestMove);
  } catch (err) {
    if ((err as Error).message !== 'CARO_AI_REQUEST_CANCELLED') {
      console.error('Lỗi tính toán AI:', err);
    }
  }
};
```

### B. Quy ước truyền State vào Worker

- Trạng thái bàn cờ bắt buộc truyền dạng chuỗi JSON `caroEngine.serialize(state)` (tận dụng validation khi deserialize, tránh structured-clone lỗi object, đồng nhất 100% với Edge Function ở **P3.2**).

### C. Giao diện Cấu hình 3 Mức Độ Khó (`levels.ts` & `search.ts`)

```typescript

export interface AiConfig {

  readonly disablePruning?: boolean;
}

  readonly move: CaroMove;

}
```
