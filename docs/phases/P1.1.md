## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. Chữ Ký `CaroState`, `CaroMove`, và `CaroOptions` (`types.ts`)

```typescript
export interface CaroOptions {
  readonly boardSize: number; // Mặc định: 15 (Giới hạn: 5..25)
  readonly winLength: number; // Mặc định: 5 (Giới hạn: 3..boardSize)
  readonly blockedTwoEndsRule: boolean; // Mặc định: true (Luật VN: chặn 2 đầu không thắng)
  readonly allowOverline: boolean; // Mặc định: true (6+ quân liên tiếp tính thắng)
}

export interface CaroState {
  readonly board: readonly number[]; // Mảng 1D length size*size (-1: trống, 0: Seat 0/X, 1: Seat 1/O)
  readonly currentPlayer: PlayerIndex; // 0 hoặc 1
  readonly moveCount: number; // Tổng số nước đi đã thực hiện
  readonly lastMove: number | null; // Flat index nước đi gần nhất (0..size*size-1)
  readonly options: CaroOptions; // Bất biến sau khởi tạo
}

export type CaroMove = number; // Flat index (0..size*size-1)
```

### C. Định Dạng Tuần Tự Hóa Nén (Serialization Specification)

Chuỗi nén trạng thái gồm 9 trường phân tách bởi dấu hai chấm `:`:

```text
v1:<boardSize>:<winLength>:<blockedTwoEnds>:<allowOverline>:<currentPlayer>:<moveCount>:<lastMove>:<boardRLE>
```

- **Ví dụ**:
  - Bàn 15x15 trống: `v1:15:5:1:1:0:0:-1:225.` (23 bytes).
  - Bàn 15x15 sau 60 nước: `v1:15:5:1:1:0:60:112:55.x2.o1.x...80.` (~100–140 bytes).

### D. Thứ Tự Validate & Mã Lỗi `EngineError` Chuẩn Hóa trong `applyMove`

| Bước kiểm tra          | Điều kiện vi phạm                                               | Mã lỗi `EngineError` | HTTP Status (Server P3.2) |
| :--------------------- | :-------------------------------------------------------------- | :------------------: | :-----------------------: |
| 1. Trạng thái kết thúc | `isTerminal(state).over === true`                               |    `'GAME_OVER'`     |     `400 Bad Request`     |

## 4. QUYẾT ĐỊNH THIẾT KẾ & ĐẶC TẢ LUẬT THẮNG

1. **Mảng 1D phẳng thay vì 2D**:
   - `index = y * size + x`. Tối ưu tốc độ duyệt mảng, cấp phát bộ nhớ liền kề (cache locality), và nén RLE siêu nhanh.
2. **Luật Chặn 2 Đầu (Luật Caro Việt Nam)**:
   - Chuỗi thắng chỉ bị vô hiệu nếu **CẢ HAI ĐẦU** đều bị chặn bởi **QUÂN ĐỐI PHƯƠNG**.
   - **Mép bàn cờ KHÔNG tính là chặn**: Chuỗi 5 quân sát biên với 1 đầu mép bàn và 1 đầu bị quân đối thủ chặn $\rightarrow$ **VẪN THẮNG**.
   - Với Overline (dãy $> \text{winLength}$): Xét chặn 2 đầu trên toàn bộ 2 đầu mút ngoài cùng của chuỗi liên tiếp tối đa.
3. **Tối ưu $\mathcal{O}(1)$ cho `isTerminal`**:
   - Quét 4 hướng qua `lastMove` thay vì duyệt toàn bộ $225$ ô, tăng tốc độ tính toán cho AI Worker duyệt hàng triệu node.

3. **Cấu trúc `CaroState` & `applyMove`**: Dùng để mô phỏng cây trò chơi trong thuật toán Minimax kết hợp Alpha-Beta Pruning.
