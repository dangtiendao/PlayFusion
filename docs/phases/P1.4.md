## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. Kiểu Cấu Hình Ván Đấu & State Machine (`src/games/caro/types.ts`)

```typescript
export interface CaroMatchConfig {
  /** Chế độ chơi */
  readonly mode: 'vs_ai' | 'local_pvp';
  /** Cấp độ AI (bắt buộc khi mode = 'vs_ai') */
  readonly aiLevel?: 'easy' | 'medium' | 'hard';
  /** Ghế người chơi: 0 (cầm X, đi trước) | 1 (cầm O, đi sau) */
  readonly humanSeat?: 0 | 1;
}

export type CaroScreen = 'setup' | 'playing' | 'finished';
```

### B. Props Màn Hình Kết Thúc Trận Đấu (`MatchEndOverlayProps`)

```typescript
export interface SessionScore {
  readonly player1Wins: number;
  readonly player2Wins: number;
  readonly draws: number;
  readonly matchNumber: number;
}

export interface MatchEndOverlayProps {
  readonly report: MatchResultReport;
  readonly matchConfig: CaroMatchConfig;
  readonly moveCount: number;
  readonly sessionScore?: SessionScore;
  readonly onRestart: () => void;
  readonly onBackToSetup: () => void;
  readonly onExit?: () => void;
  readonly shellApi?: GameShellApi;
}
```

### C. Luật Đổi Lượt Đi Trước Khi Chơi Lại (Alternate First-Mover Contract)

- **Đấu máy (`vs_ai`)**: Đảo `humanSeat = (currentSeat === 0 ? 1 : 0)`.
  - Ván 1: Người X (đi trước) $\rightarrow$ Ván 2: Người O (đi sau, máy X tự mở màn).
- **2 người 1 máy (`local_pvp`)**: Đảo thứ tự bên cầm quân X đi trước giữa 2 người chơi.

## 7. ĐẦU VÀO GỢI Ý CHO PHASE KẾ TIẾP (P1.5 — Local Storage & Persistence)

1. **`CaroMatchConfig`**: Đọc/ghi cấu hình gần nhất vào `localStorage` (`lastSelectedMode`, `lastAiLevel`, `lastHumanSeat`).
2. **`SessionScore`**: Mở rộng thành Bảng thống kê lịch sử đấu (Wins/Losses/Draws) lưu cục bộ theo từng chế độ.
3. **`caroEngine.serialize(gameState)`**: Lưu ván cờ đang chơi dở khi thoát và khôi phục khi quay lại `/game/caro`.
4. **Lưu ý an toàn**: Bắt buộc gọi `cancel()` trên `useCaroAi` trước khi load game đã lưu hoặc thực hiện Undo.
