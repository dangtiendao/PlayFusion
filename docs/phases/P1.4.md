## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. Kiểu Dữ Liệu Cấu Hình Trận Đấu (`CaroMatchConfig`)

```typescript
import type { AiLevel, PlayerIndex } from '@engines/types';

export interface CaroMatchConfig {
  /** Chế độ chơi: Đấu máy ('vs_ai') hoặc 2 người trên cùng máy ('local_pvp') */
  readonly mode: 'vs_ai' | 'local_pvp';
  /** Cấp độ khó của AI (bắt buộc khi mode = 'vs_ai') */
  readonly aiLevel?: AiLevel; // 'easy' | 'medium' | 'hard'
  /**
   * Vị trí ghế người chơi (chỉ áp dụng khi mode = 'vs_ai'):
   * - 0: Người chơi cầm quân X (đi trước).
   * - 1: Người chơi cầm quân O (đi sau, máy mở màn).
   */
  readonly humanSeat?: PlayerIndex;
}

export type CaroScreen = 'setup' | 'playing' | 'finished';
```

### B. Props Màn Hình Kết Thúc Trận Đấu (`MatchEndOverlayProps`)

```typescript
export interface SessionScore {
  readonly player1Wins: number;
  readonly player2Wins: number;
  readonly draws: number;
  readonly matchNumber: number;
}

export interface MatchEndOverlayProps {
  readonly report: MatchResultReport;
  readonly matchConfig: CaroMatchConfig;
  readonly moveCount: number;
  readonly sessionScore?: SessionScore;
  readonly onRestart: () => void;
  readonly onBackToSetup: () => void;
  readonly onExit?: () => void;
  readonly shellApi?: GameShellApi;
}
```

### C. Luật Đổi Lượt Khi Chơi Lại (Alternate First-Mover Contract)

- **Đấu máy (`vs_ai`)**: Đảo `humanSeat = (currentSeat === 0 ? 1 : 0)`.
  - Ván 1: Người X $\rightarrow$ Ván 2: Người O (Máy X mở màn).
- **2 người 1 máy (`local_pvp`)**: Đảo thứ tự quyền đi trước giữa 2 người chơi.

## 6. RỦI RO & ĐIỂM CẦN LƯU Ý CHO PHASE SAU (P1.5+)

1. **State Machine Bất Biến**: Không được chuyển thẳng màn hình `setup` $\rightarrow$ `finished` mà luôn phải đi qua `playing` để đảm bảo `startTimeRef` và `matchSeedRef` được khởi tạo chuẩn xác.
2. **Double-layer Async Protection**: Khi thêm tính năng `Undo` hoặc `Load Saved Game` ở P1.5, **bắt buộc** phải gọi `cancel()` trên `useCaroAi` trước khi thay đổi `gameState` để tránh Worker ghi đè nước đi cũ.
3. **Pháo giấy Confetti**: Luôn giữ class `motion-reduce:hidden` trên container để đảm bảo trải nghiệm trợ năng (Accessibility) trên các thiết bị bật giảm chuyển động.

## 7. ĐẦU VÀO CHO PHASE TIẾP THEO (P1.5 — Local Storage & Persistence)

Phase P1.5 sẽ sử dụng các thành phần sau của P1.4:

1. `CaroMatchConfig`: Cấu hình ván đấu để lưu lại lựa chọn gần nhất của người dùng (`lastSelectedMode`, `lastAiLevel`, `lastHumanSeat`).
2. `SessionScore`: Cấu trúc dữ liệu để mở rộng thành Thống kê thắng/thua/hòa dài hạn (Local Stats & Match History).
3. `caroEngine.serialize(gameState)` / `caroEngine.deserialize(json)`: Khả năng lưu ván cờ đang chơi dở vào `localStorage` và khôi phục khi người dùng mở lại trang `/game/caro`.
