## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS CHO P1.2c)

### A. Giao diện Cấu hình & Kết quả Tìm kiếm (`search.ts`)

```typescript
export interface AiConfig {
  /** Cấp độ thông minh ('easy' | 'medium' | 'hard') */
  readonly level: AiLevel;
  /** Hạt giống ngẫu nhiên (string hoặc number) để đảm bảo 100% Deterministic */
  readonly seed?: string | number;
  /** Giới hạn thời gian tính toán tối đa (ms). Nếu không truyền, dùng mặc định của level */
  readonly timeBudgetMs?: number;
  /** Hàm đo thời gian tiêm được (phục vụ Unit Test determinism & timeout simulation) */
  readonly now?: () => number;
  /** Cờ nội bộ cho phép tắt Alpha-Beta pruning trong test */
  readonly disablePruning?: boolean;
}

export interface AiResult {
  /** Nước đi tối ưu nhất được chọn (flat index 0..size*size-1) */
  readonly move: CaroMove;
  /** Điểm số lượng giá của nước đi */
  readonly score: number;
  /** Độ sâu tìm kiếm hoàn chỉnh cao nhất đạt được */
  readonly depth: number;
  /** Tổng số node trên cây trạng thái đã được duyệt qua */
  readonly nodes: number;
  /** Thời gian tính toán thực tế (mili-giây) */
  readonly elapsedMs: number;
}

export function findBestMove(state: CaroState, config: AiConfig): AiResult;
```

### B. Giao diện Cấu hình Mức độ Khó (`levels.ts`)

```typescript
export type AiLevel = 'easy' | 'medium' | 'hard';

export interface AiLevelConfig {
  readonly level: AiLevel;
  readonly maxDepth: number;

  readonly candidateRadius: number;
  readonly timeBudgetMs: number;
  readonly noiseProbability: number;
  readonly forgetBlockProbability: number;
}

export const AI_LEVELS: Record<AiLevel, AiLevelConfig>;
export function getAiLevelConfig(level: AiLevel): AiLevelConfig;
```

## 4. QUYẾT ĐỊNH THIẾT KẾ TRONG PHASE

| Quyết định                                                           | Lý do lựa chọn                                                                                                                                                                                    | Phương án đã loại bỏ                                                                                                      |
| :------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------ |
| **Thứ tự quyết định 3 bước (a) $\rightarrow$ (b) $\rightarrow$ (c)** | Tối ưu hóa thời gian: nếu có nước thắng ngay hoặc đối thủ đe dọa thắng ngay, không cần duyệt Minimax sâu tốn tài nguyên.                                                                          | _Chạy thẳng vào Minimax_: Tốn thời gian duyệt cây cho các tình huống hiển nhiên.                                          |
| **Kỹ thuật Depth-biased Terminal Score**                             | Điểm thắng $+WIN + \text{depth}$ thúc đẩy AI chọn đường thắng ngắn nhất; điểm thua $-WIN - \text{depth}$ buộc AI chọn đường kháng cự lâu nhất.                                                    | _Điểm thắng/thua cố định ($\pm WIN$)_: Khiến AI chần chừ không dứt điểm ván đấu hoặc đầu hàng sớm.                        |
| **Iterative Deepening chỉ commit độ sâu hoàn chỉnh**                 | Khi hết timeBudget giữa chừng ở tầng $d$, kết quả của tầng $d$ chưa được duyệt hết nhánh $\rightarrow$ có thể chứa nước đi sai lầm nghiêm trọng (blunder). Chỉ lưu kết quả tầng $d-1$ hoàn chỉnh. | _Lấy kết quả dở dang_: Gây ra các nước đi ngớ ngẩn khi AI bị ngắt giữa chừng.                                             |
| **Mức Dễ "cố tình quên chặn" loại bỏ ô chặn**                        | Khi xác suất `forgetBlockProbability` kích hoạt, AI chọn nước đi trong tập không chặn để người mới học chơi có cơ hội chiến thắng.                                                                | _Bỏ qua bước b nhưng để Minimax chọn_: Minimax vẫn cho điểm chặn rất cao dẫn đến AI luôn chặn dù đã roll trúng quên chặn. |
| **Bọc hàm đo thời gian `defaultNow()` tiêm được**                    | Duy trì quy tắc Pure Engine không phụ thuộc biến môi trường ngầm, cho phép mock `now()` để test timeout chính xác 100%.                                                                           | _Gọi trực tiếp `Date.now()` rải rác_: Khiến test bất định phụ thuộc vào tốc độ CPU của máy chạy test.                     |

## 7. ĐẦU VÀO CHO PHASE KẾ TIẾP (P1.2c — WEB WORKER & COMLINK BRIDGE)

Phase **P1.2c** sẽ đóng gói module AI Caro vào Web Worker:

1. **Web Worker Entry (`caro.worker.ts`)**: Import `findBestMove` và expose qua Comlink.
2. **Comlink RPC Interface**: Khai báo interface RPC cho phép UI gọi `findBestMoveAsync(state, config)` mà không làm đơ main UI thread (60 FPS).
3. **Fallback Graceful**: Hỗ trợ chạy trực tiếp trên main thread nếu môi trường không hỗ trợ Web Worker.
