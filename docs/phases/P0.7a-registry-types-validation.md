- **Mã phase**: `P0.7a`

## 1. Các thành phần đã triển khai

### A. Định nghĩa Kiểu Đăng ký Game (`src/games/types.ts`)

- `GameViewProps`: `{ readonly definition: GameDefinition }`.
  - JSDoc quy định nguyên tắc mở rộng cho Phase P0.8 (GameShell) và P1.x: Chỉ THÊM các trường optional mới, không sửa trường đã có.
- `RegistryEntry`: `{ readonly definition: GameDefinition; readonly loadView: () => Promise<{ default: React.ComponentType<GameViewProps> }> }`.
  - Chuẩn hóa chữ ký cho `React.lazy()` phục vụ lazy loading tách bundle theo từng game độc lập.

### B. View Mẫu Tham Chiếu Dummy (`src/games/dummy/View.tsx`)

- Component React default export nhận `GameViewProps`.
- Nạp engine động qua `definition.loadEngine()` với `useEffect` + trạng thái `loading` và `loadError`.
- Kế thừa toàn bộ giao diện và chức năng kiểm chứng engine từ `DummyEngineDemo`.
- Comment: _"View mẫu tham chiếu — game thật P1.x copy cấu trúc."_

### C. Module Registry Tập Trung (`src/games/registry.ts`)

- Mảng đăng ký bất biến `GAMES: readonly RegistryEntry[] = [{ definition: dummyManifest, loadView: () => import('./dummy/View') }]`.
- Các hàm API tra cứu:
  - `getGameById(id: string): RegistryEntry | undefined`
  - `getAllGames(): readonly RegistryEntry[]`
  - `getGamesByCategory(category: GameCategory): readonly RegistryEntry[]`
- Cơ chế **Fail-Fast**:
  - `validateRegistry(entries)`: Kiểm tra trùng lặp `id`, validate từng manifest qua `validateGameDefinition`, và kiểm tra `loadView`.
  - `assertRegistryValid(entries)`: Tự động chạy ngay khi module được import. Nếu có lỗi cấu hình, lập tức throw Error và dừng app dev.

### D. Tái cấu trúc Trang Chủ & Dọn dẹp

- Gỡ bỏ `DummyEngineDemo` khỏi `src/pages/HomePage.tsx`, thay bằng placeholder tạm thời chờ P0.7b.
- Xóa bỏ file `src/components/DummyEngineDemo.tsx`.

### E. Bộ Unit Tests (`src/games/registry.test.ts`)

- 8/8 test cases bao phủ: tra cứu `getGameById`, `getAllGames`, `getGamesByCategory`, `assertRegistryValid` pass với `GAMES`, bắt lỗi khi trùng ID, bắt lỗi khi manifest sai logic, và bắt lỗi khi `loadView` sai kiểu.
