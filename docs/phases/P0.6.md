## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. Interface `Engine<S, M>` (`@engines/types`)

```typescript
export interface Engine<S, M> {
  init(config: EngineInitConfig): S;
  legalMoves(state: S, playerIndex: PlayerIndex): M[];
  applyMove(state: S, move: M, playerIndex: PlayerIndex): S;
  currentPlayer(state: S): PlayerIndex;
  isTerminal(state: S): TerminalResult;
  serialize(state: S): string;
  deserialize(data: string): S;

  // Phương thức mở rộng tùy chọn
  viewFor?(state: S, playerIndex: PlayerIndex): unknown;
  serializeMove?(move: M): string;
  deserializeMove?(data: string): M;
}
```

### B. Interface `GameDefinition` (`@engines/types`)

```typescript
export interface GameDefinition {
  readonly id: string;
  readonly name: string;
  readonly description: string;
  readonly category: GameCategory;
  readonly players: { readonly min: number; readonly max: number };
  readonly modes: readonly GameMode[];
  readonly turnBased: boolean;
  readonly ranked: boolean;
  readonly scoring: ScoringType;
  readonly ratingSystem: RatingSystem;
  readonly hasDraw: boolean;
  readonly avgMatchSeconds: number;
  readonly loadEngine: () => Promise<Engine<unknown, unknown>>;

  // Thuộc tính mở rộng
  readonly icon?: string;
  readonly themeColor?: string;
  readonly aiLevels?: readonly AiLevel[];
  readonly seeded?: boolean;
  readonly hiddenInfo?: boolean;
  readonly timeControl?: TimeControlConfig;
  readonly cosmeticSlots?: readonly CosmeticSlotDefinition[];
  readonly minAppVersion?: string;
  readonly scoreDirection?: ScoreDirection;
}
```

### C. Class Lỗi `EngineError` (`@engines/types`)

```typescript
export type EngineErrorCode = 'ILLEGAL_MOVE' | 'INVALID_STATE' | 'WRONG_TURN' | 'GAME_OVER';

export class EngineError extends Error {
  public readonly code: EngineErrorCode;
  public readonly details?: unknown;
  constructor(code: EngineErrorCode, message: string, details?: unknown);
}
```

### D. Hàm Kiểm Định `validateGameDefinition`

```typescript
export function validateGameDefinition(def: GameDefinition): string[];
```

_Ví dụ import và sử dụng trong toàn bộ hệ thống:_

```typescript
import {
  type Engine,
  type GameDefinition,
  EngineError,
  validateGameDefinition,
} from '@engines/types';
import { dummyEngine } from '@engines/dummy/engine';
import { dummyManifest } from '@engines/dummy/manifest';

// Kiểm tra manifest
const errors = validateGameDefinition(dummyManifest);
if (errors.length > 0) throw new Error(errors.join('\n'));

// Chạy engine
const state = dummyEngine.init({ playerCount: 2 });
const nextState = dummyEngine.applyMove(state, { playerIndex: 0, points: 3 }, 0);
```

## 4. QUYẾT ĐỊNH THIẾT KẾ

| Quyết định                                 | Lý do lựa chọn                                                                                                                                   | Phương án đã loại bỏ & Lý do loại                                                                         |
| :----------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------- |
| **Engine dùng Hàm thuần (Pure Functions)** | Đảm bảo deterministic tuyệt đối: Cùng 1 input luôn ra cùng 1 output. Cho phép chạy mượt trên cả Client, Worker AI, và Server Edge Function Deno. | _Class-based Stateful Engine_: Khó serialize, dễ rò rỉ bộ nhớ, và khó đồng bộ qua mạng.                   |
| **`Engine<unknown, unknown>` ở Manifest**  | Cho phép hệ thống tải động (dynamic import) và quản lý game mà không cần biết kiểu dữ liệu cụ thể của từng trò chơi.                             | _Generic GameDefinition<S, M>_: Làm toàn bộ Registry và Sảnh game bị phụ thuộc kiểu dữ liệu của mọi game. |
| **Hàm `validateGameDefinition` Fail-Fast** | Bắt sớm các mâu thuẫn cấu hình ngay lúc dev (ví dụ có `vs_ai` mà thiếu `aiLevels`, tính điểm mà thiếu `scoreDirection`).                         | _Để mặc định runtime tự kiểm tra_: Dễ sót lỗi khi phát hành game lên production.                          |
| **Ném lỗi bằng `EngineError` có code**     | Giúp Edge Function trên Deno map thẳng sang HTTP 400 Bad Request, và Client UI phân loại để hiển thị cảnh báo phù hợp.                           | _Throw generic Error string_: Khó phân biệt nguyên nhân lỗi giữa sai luật và sai lượt.                    |

## 7. ĐẦU VÀO GỢI Ý CHO PHASE KẾ TIẾP (P0.7 — Registry & Menu Game Động)

Phase **P0.7** sẽ xây dựng Module `src/core/registry.ts` để nạp động các game và render Sảnh trò chơi / Route `/game/:gameId`. Cần nắm rõ các đầu vào từ P0.6:

1. **Import `GameDefinition` & `validateGameDefinition`**: Registry sẽ import interface `GameDefinition` và gọi `validateGameDefinition(manifest)` cho mọi game đăng ký.
2. **Khai báo `loadEngine`**: Registry sẽ gọi `manifest.loadEngine()` khi người chơi bắt đầu vào phòng đấu để kích hoạt dynamic import code-splitting.
3. **Khai báo Chế độ chơi (`modes`)**: Sảnh game và menu chọn chế độ sẽ đọc mảng `manifest.modes` để render các nút bấm tương ứng (`vs_ai`, `local_pvp`, `online_1v1`).
4. **Khuôn mẫu tham chiếu**: `packages/engines/dummy/manifest.ts` và `packages/engines/dummy/engine.ts` là mẫu chuẩn để P0.7 nạp thử nghiệm vào Registry.
