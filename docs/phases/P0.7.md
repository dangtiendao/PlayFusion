## 3. HỢP ĐỒNG CÔNG KHAI (PUBLIC CONTRACTS)

### A. Quy Trình Thêm Game Mới 3 Bước (Quy Tắc "1 Dòng Registry")

Khi một game mới được xây dựng (ví dụ Caro ở Phase P1.x):

1. **Bước 1**: Tạo thư mục Engine tại `packages/engines/<gameId>/` chứa `engine.ts` và `manifest.ts` (chuẩn `GameDefinition`).
2. **Bước 2**: Tạo thư mục UI tại `src/games/<gameId>/` chứa `View.tsx` (nhận `GameViewProps`).
3. **Bước 3**: Mở `src/games/registry.ts`, import manifest và thêm đúng 1 dòng vào mảng `GAMES`:

```typescript
export const GAMES: readonly RegistryEntry[] = [
  // ... các game hiện có ...
  { definition: caroManifest, loadView: () => import('./caro/View') },
];
```

_(Hệ thống sẽ tự động sinh thẻ trên Trang chủ, tự sinh chip lọc thể loại, hỗ trợ tìm kiếm, và mở route `/game/caro` ngay lập tức)._

### B. Interface `RegistryEntry` & `GameViewProps` (`src/games/types.ts`)

```typescript
export interface GameViewProps {
  readonly definition: GameDefinition;
  // Phase P0.8 & P1.x sẽ mở rộng thêm: mode?: GameMode; onGameOver?: (report: MatchResultReport) => void;
}

export interface RegistryEntry {
  readonly definition: GameDefinition;
  readonly loadView: () => Promise<{ default: React.ComponentType<GameViewProps> }>;
}
```

### C. API Tra Cứu Registry (`src/games/registry.ts`)

```typescript
export function getGameById(id: string): RegistryEntry | undefined;
export function getAllGames(): readonly RegistryEntry[];
export function getGamesByCategory(category: GameCategory): readonly RegistryEntry[];
export function assertRegistryValid(entries?: readonly RegistryEntry[]): void;
```

### D. Cam Kết Code-Splitting Tuyệt Đối

- Người chơi ở Trang chủ hoặc chơi Game A **tuyệt đối không tải** chunk JavaScript của Game B.
- Cả `loadView` (giao diện React) và `loadEngine` (logic luật cờ) đều là Dynamic Import (`import()`).

## 4. QUYẾT ĐỊNH THIẾT KẾ

| Quyết định                                     | Lý do lựa chọn                                                                                                           | Phương án đã loại bỏ & Lý do loại                                                                            |
| :--------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------- |
| **Route Động Duy Nhất `/game/:gameId`**        | Giúp hệ thống không cần khai báo route tĩnh cho từng game; mở rộng game mới không cần chạm vào router.                   | _Khai báo `/game/caro`, `/game/co-tuong` riêng_: Làm router bị phình to và vi phạm tính đóng kín của plugin. |
| **`useMemo` Bọc `React.lazy(entry.loadView)`** | Giữ ổn định Component Factory giữa các lần re-render của GamePage, ngăn chặn React unmount/remount làm mất state ván cờ. | _Gọi `React.lazy` trực tiếp trong component_: Mỗi lần state thay đổi bàn cờ bị reset trắng.                  |
| **Nút Back Dùng `<Link to="/">`**              | Đảm bảo an toàn 100% khi người dùng truy cập trực tiếp bằng URL chia sẻ/bookmark (không có browser history trước đó).    | _Chỉ dùng `navigate(-1)`_: Người dùng vào trực tiếp sẽ bị văng ra khỏi website.                              |
| **Validation Fail-Fast Tự Động**               | Bắt lỗi cấu hình manifest và trùng lặp ID ngay lúc khởi động dev, ngăn lỗi lọt vào production.                           | _Để runtime tự crash_: Khó debug khi số lượng game lớn.                                                      |

## 6. HƯỚNG DẪN VẬN HÀNH & KIỂM CHỨNG CODE-SPLITTING

### A. Kiểm Chứng Code-Splitting Trong DevTools Network:

1. Chạy `npm run build && npm run preview` (hoặc mở trang deploy Cloudflare Pages).
2. Mở **Chrome DevTools** $\rightarrow$ Tab **Network** $\rightarrow$ Chọn lọc **JS**.
3. Tải lại Trang chủ (`/`):
   - **Xác nhận**: Chỉ tải bundle chính (`index-*.js`, `HomePage-*.js`). Tuyệt đối **không tải** các chunk `View-*.js` hay `engine-*.js` của dummy/dummy2.
4. Bấm vào thẻ game **Dummy Test Game**:
   - **Xác nhận**: Trình duyệt mới bắt đầu gửi request tải thêm chunk `View-*.js` và `engine-*.js`.

### B. Bài Kiểm Tra "Thêm Game = 1 Dòng":

- Game `dummy2` (thuộc thể loại `puzzle`) đã được đăng ký và chứng minh 5 tiêu chí:
  1. Tự động xuất hiện thẻ game `Dummy 2 Puzzle` trên Trang chủ.
  2. Tự động xuất hiện chip lọc thể loại `🧩 Giải đố (1)`.
  3. Tìm kiếm từ khóa "puzzle" hiển thị đúng `dummy2`.
  4. Bấm vào thẻ game chuyển hướng mượt mà sang `/game/dummy2` và chơi được.
  5. Chunk tách riêng và lazy load đúng chuẩn.
