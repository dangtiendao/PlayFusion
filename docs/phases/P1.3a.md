## 1. TÓM TẮT KẾT QUẢ

1. **Quyết định công nghệ render**: Sử dụng **DOM CSS Grid + SVG Inline Vectors** (không dùng Canvas/Phaser).
   - Tối ưu re-render vượt trội với `React.memo(CaroCell)` ($\mathcal{O}(1)$ update khi đánh 1 nước: chỉ 2 ô re-render).
   - SVG vector nét bo tròn đảm bảo độ sắc nét 100% trên màn hình Retina / Mobile High-DPI.
   - CSS Transitions và Animations (`scale-in` ~120ms, `animate-pulse` khi thắng) mượt mà qua GPU Compositor.
2. **Component hiển thị thuần `BoardView.tsx`**:
   - Chỉ nhận props (`board`, `boardSize`, `lastMove`, `winLine`, `previewCell`, `previewPlayer`, `cellSizePx`, `onCellPointerDown`).
   - Hoàn toàn độc lập, không import engine, AI, hay store (tái sử dụng dễ dàng cho tính năng Replay ở P8.1).
3. **Component con `CaroCell.tsx` bọc `React.memo`**:
   - Nhận toàn bộ props kiểu nguyên thủy (primitive) để shallow compare đạt hiệu quả tuyệt đối.
   - Hiển thị đầy đủ các trạng thái: Ô trống, Quân X (Cyan), Quân O (Rose), Last Move (Viền xanh tím + chấm góc), Win Line (Nền hổ phách + Pulse), Preview Cell (Nét đứt + mờ 50%).
4. **Trang demo kiểm chứng `BoardDemo.tsx`**:
   - Đăng ký route `/dev/board-demo` (`showInNav: false`).
   - Hiển thị 3 bàn cờ mẫu: Bàn giữa ván 15x15 có lastMove, Bàn thắng cuộc 11x11 có winLine, Bàn trống 9x9 có previewCell.
   - Có slider chỉnh `cellSizePx` từ 20px đến 48px kiểm chứng responsive.
5. **Kiểm thử**: Đạt 100% code coverage trên `src/games/caro/components/`, 29 test files (209/209 tests) pass sạch sẽ.
