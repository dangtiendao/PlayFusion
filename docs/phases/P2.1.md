## 4. Quyết Định Thiết Kế (Design Decisions)

1. **Endpoint `/auth/v1/health` thay vì `supabase.from()`**:
   - Ở phase này, database chưa có bất kỳ bảng nào. Việc gọi query bảng sẽ gây lỗi HTTP 404 hoặc 400.
   - Endpoint GoTrue `/auth/v1/health` luôn khả dụng với mã HTTP 200 khi project đang hoạt động, cho phép đo latency thực tế mà không phụ thuộc DB schema.
2. **Cổng Thoát Hiểm (Escape Hatch Architecture)**:
   - Toàn bộ component UI (`src/pages`, `src/components`, `src/games`), State Store (`src/stores`), và Game Engine (`packages/engines`) tuyệt đối không phụ thuộc trực tiếp vào Supabase SDK.
   - Khi cần đổi nhà cung cấp backend trong tương lai, toàn bộ mã nguồn bên ngoài `src/repositories/` giữ nguyên vẹn 100%.
3. **Fail-Fast Validation**:
   - Thiếu biến môi trường sẽ báo lỗi ngay khi dev server khởi động thay vì để xảy ra lỗi ngầm khó truy vết khi người dùng tương tác.
