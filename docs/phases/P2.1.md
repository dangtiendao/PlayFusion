## 1. Tóm Tắt (Executive Summary)

Phase P2.1 đã hoàn thành trọn vẹn 2 phần nền tảng cốt lõi của Nhóm 2:

1. **P2.1a — Hạ Tầng & Tầng Repositories**:
   - Thiết lập kết nối 2 project Supabase (`webgamehub-dev` và `webgamehub-prod`) tại Singapore (`ap-southeast-1`).
   - Khởi tạo client singleton `src/repositories/supabaseClient.ts`, kiểm định biến môi trường fail-fast `src/core/env.ts`.
   - Thiết lập hàng rào phụ thuộc `dependency-cruiser` cấm triệt để import Supabase SDK ngoài `src/repositories/` ("Cổng thoát hiểm").
   - Health check kết nối máy chủ không phụ thuộc bảng DB qua GoTrue `/auth/v1/health`.
2. **P2.1b — Luồng Xác Thực (Đăng Nhập Ẩn Danh + Google OAuth + Nâng Cấp Không Mất ID)**:
   - **Vào là chơi ngay (Khách Ẩn Danh)**: Tự động khởi tạo phiên khách `signInAnonymously()` khi mở app mà không chặn giao diện offline.
   - **Nâng cấp bảo toàn dữ liệu (Zero Data Loss)**: Dùng `linkIdentity` để nâng cấp tài khoản khách lên Google **giữ nguyên `user.id`** $\rightarrow$ toàn bộ lịch sử, thống kê offline/online không bị mất.
   - **Quản lý phiên qua Zustand Store**: `useAuthStore` không persist (để Supabase SDK tự quản lý token), chống double-init trong React StrictMode.
   - **UI chẩn đoán tài khoản**: Hiển thị ID rút gọn, badge Khách/Google, nút Đăng nhập Google, và nút Đăng xuất (kèm cảnh báo an toàn cho khách) tại `SettingsPage`.

## 3. Hợp Đồng Công Khai (Public API Contract)

### A. Auth Repository (`src/repositories/authRepository.ts`)

```typescript
export interface AppAuthUser {
  readonly id: string;
  readonly isAnonymous: boolean;
  readonly email?: string;
  readonly displayName?: string;
  readonly avatarUrl?: string;
  readonly provider?: string;
}

export function formatAuthUser(user: User | null): AppAuthUser | null;
export function getSession(): Promise<Session | null>;
export function getUser(): Promise<AppAuthUser | null>;
export function signInAnonymously(): Promise<AppAuthUser>;
export function signInWithGoogle(options?: { redirectTo?: string }): Promise<void>;
export function linkGoogleToAnonymous(options?: { redirectTo?: string }): Promise<void>;
export function signOut(): Promise<void>;
export function onAuthStateChange(
  callback: (event: AuthChangeEvent, user: AppAuthUser | null) => void,
): { unsubscribe: () => void };
```

### B. Auth Store (`src/stores/authStore.ts`)

```typescript
export type AuthStatus = 'loading' | 'authenticated' | 'unauthenticated' | 'error';

export interface AuthState {
  readonly user: AppAuthUser | null;
  readonly status: AuthStatus;
  readonly error: string | null;
  readonly isInitialized: boolean;

  readonly init: () => Promise<void>;
  readonly signInWithGoogle: (options?: { redirectTo?: string }) => Promise<void>;
  readonly linkGoogle: (options?: { redirectTo?: string }) => Promise<void>;
  readonly signOut: () => Promise<void>;
  readonly clearError: () => void;
}

export const useAuthStore: UseBoundStore<StoreApi<AuthState>>;
export const useAuthUser: () => AppAuthUser | null;
export const useIsAnonymous: () => boolean;
export const useIsSignedInWithProvider: () => boolean;
export const useAuthStatus: () => AuthStatus;
```
