## 1. Các thành phần đã triển khai

### A. Hạ tầng kiểm thử Vitest

- Tích hợp Vitest trực tiếp vào [vite.config.ts](file:///e:/Project/PlayFusion/vite.config.ts), chia sẻ toàn bộ path alias `@/` và `@engines/`.
- Môi trường test mặc định: `environment: 'node'` (chạy siêu nhanh cho pure game engines).
- Cấu hình sẵn sàng hỗ trợ `jsdom` khi test UI React components.
- Thu thập code coverage qua `@vitest/coverage-v8` (`npm run test:coverage`).

### B. Unit Test mẫu

- [packages/engines/\_smoke.test.ts](file:///e:/Project/PlayFusion/packages/engines/_smoke.test.ts) kiểm thử 5 trường hợp cho hàm pure logic:
  1. Khởi tạo state mặc định (`score = 0`, `multiplier = 1`).
  2. Cộng điểm chuẩn xác khi `multiplier = 1`.
  3. Tính điểm kết hợp hệ số nhân `multiplier`.
  4. Tính bất biến (Immutability): State cũ không bị mutate khi tính state mới.
  5. Xử lý an toàn khi cộng 0 điểm hoặc điểm âm.

4. [`src/pages/README.md`](file:///e:/Project/PlayFusion/src/pages/README.md): Views các màn hình chính (Home, Profile, Match, Admin...).
5. [`src/repositories/README.md`](file:///e:/Project/PlayFusion/src/repositories/README.md): Tầng truy xuất dữ liệu Supabase DB.
