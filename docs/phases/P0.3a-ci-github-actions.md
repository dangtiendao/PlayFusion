# Nghiệm thu Phase P0.3a: CI GitHub Actions (Quality Gate)

- **Mã phase**: `P0.3a`
- **Mục tiêu**: Mọi push/PR đều được kiểm tra tự động đủ 6 cổng chất lượng, nhanh nhờ cache npm, timeout 10 phút, và lưu trữ artifact.
- **Trạng thái**: ✅ **HOÀN THÀNH 100% (DoD Approved)**

---

## 1. Các thành phần đã triển khai

### A. Pipeline CI GitHub Actions (`.github/workflows/ci.yml`)

- **Trigger**: `push` lên mọi branch (`**`) và `pull_request` vào `main`/`master`.
- **Runner**: `ubuntu-latest`.
- **Node Setup**: `actions/setup-node@v4` đọc trực tiếp từ `.nvmrc` (`node-version-file: '.nvmrc'`), tự động cache `cache: 'npm'`.
- **7 Bước Tuần Tự (6 Cổng Chất Lượng)**:
  1. `npm ci` (Cài đặt dependencies sạch từ lockfile).
  2. **Cổng 1 (Linting)**: `npm run lint` (ESLint 9 + Hàng rào chặn `packages/engines` import React/UI).
  3. **Cổng 2 (Format)**: `npm run format:check` (Prettier code style).
  4. **Cổng 3 (Typecheck)**: `npm run typecheck` (`tsc -b` kiểm tra kiểu nghiêm ngặt và cách ly DOM).
  5. **Cổng 4 (Architecture)**: `npm run check:deps` (`dependency-cruiser` cấm circular và cấm phụ thuộc ngược).
  6. **Cổng 5 (Unit Tests)**: `npm run test` (Vitest node environment test).
  7. **Cổng 6 (Production Build)**: `npm run build` (Vite production bundle).
- **Upload Artifact**: `actions/upload-artifact@v4` lưu trữ thư mục `dist/` (retention 5 ngày).
- **Tiết kiệm Quota & Timeout**:
  - `concurrency: { group: ${{ github.workflow }}-${{ github.ref }}, cancel-in-progress: true }`.
  - `timeout-minutes: 10`.

### B. Cập nhật Tài liệu Hướng dẫn (`README.md`)

- Bổ sung chi tiết 6 cổng kiểm soát chất lượng và cách theo dõi kết quả trên tab GitHub Actions.

## 3. Hướng dẫn kiểm tra DoD trên GitHub sau khi Push

### A. Kiểm tra Workflow Xanh (Happy Path):

1. Chạy lệnh commit và push lên GitHub theo hướng dẫn bên dưới.
2. Mở GitHub Repository $\rightarrow$ Chuyển sang tab **Actions**.
3. **Kỳ vọng**: Workflow **"CI Quality Gate"** kích hoạt, chạy tuần tự qua 7 bước và hiển thị dấu tích xanh ✅ toàn bộ (~1-2 phút lần đầu, ~30-45 giây các lần sau nhờ cache npm).
4. Kiểm tra mục **Artifacts** ở dưới cùng trang workflow run $\rightarrow$ Thấy file `production-dist.zip`.

### B. Kiểm tra Bắt Lỗi Tự Động (Negative Test):

1. Tạo một branch thử nghiệm: `git checkout -b test-ci-fail`.
2. Cố ý sửa `src/App.tsx` thêm biến không dùng: `const unusedVar = 123;` hoặc làm sai 1 test trong `packages/engines/dummy/engine.test.ts`.
3. Commit và push branch lên: `git push origin test-ci-fail`.
4. Mở tab **Actions** $\rightarrow$ **Kỳ vọng**: Workflow dừng lại ngay tại bước tương ứng (**Cổng 1 - Linting** hoặc **Cổng 5 - Unit Tests**) và báo ❌ Đỏ, không chạy các bước tiếp theo.
5. Xóa branch thử nghiệm sau khi xác nhận.
