# CHECKLIST KIỂM CHỨNG 2 THIẾT BỊ THẬT: REALTIME TRANSPORT (PHASE P3.1C)

**Dự án**: Web Game Hub (PlayFusion)  
**Mục tiêu**: Xác thực khả năng truyền thông Realtime Broadcast & Presence trên mạng Internet thật giữa 2 thiết bị vật lý độc lập, đồng thời đối soát Supabase Dashboard để chứng minh **0 kết nối ngầm ngoài ván đấu** (bảo toàn hạn mức 200 CCU Free Tier).

---

## 1. HƯỚNG DẪN THIẾT LẬP MÔI TRƯỜNG KIỂM CHỨNG

### A. Chuẩn Bị Thiết Bị

1. **Thiết bị 1 (Mobile)**: Điện thoại thông minh sử dụng kết nối dữ liệu di động **4G / 5G** (hoàn toàn tách biệt mạng local).
2. **Thiết bị 2 (Desktop / Laptop / Mobile thứ hai)**: Máy tính hoặc điện thoại kết nối mạng **Wi-Fi**.
3. **Địa chỉ truy cập**:
   - Truy cập URL Cloudflare Pages Preview hoặc Deploy: `https://<ten-mien-deploy>/dev/transport-demo`
   - Hoặc môi trường Local Network (nếu test qua mạng LAN): `http://<IP-may-tinh>:5173/dev/transport-demo`

### B. Hướng Dẫn Mở Supabase Dashboard Xem Số Lượng Kết Nối (CCU)

1. Đăng nhập vào [Supabase Dashboard](https://supabase.com/dashboard).
2. Chọn Project của PlayFusion.
3. Điều hướng theo menu bên trái:
   - **Đường dẫn chính**: **Reports** $\rightarrow$ **Realtime** (hoặc **Project Settings** $\rightarrow$ **Infrastructure / Quotas**).
   - **Chỉ số cần xem**: **Concurrent Clients (CCU)** hoặc **Connected Clients / Active Connections**.
   - **Lưu ý giao diện Supabase**: Nếu Supabase cập nhật vị trí menu, chỉ số kết nối Realtime luôn nằm trong nhóm **Reports** hoặc **Database** $\rightarrow$ **Realtime** tab.
