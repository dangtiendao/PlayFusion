## 2. HƯỚNG DẪN DỰNG DỮ LIỆU ĐỐI CHIẾU TRÊN DEV (REPRODUCTION STEPS)

### Cách 1: Đấu tay tự nhiên trên 2 Tab Dev

1. Mở Tab 1 (User A) và Tab 2 (User B) cùng vào phòng Ranked Cờ Caro.
2. Đánh đủ 5 nước đi để qua ngưỡng tối thiểu $\ge 3$ nước (tránh abort).
3. Cho một bên thắng hoặc bấm Đầu hàng $\rightarrow$ Quan sát Overlay kết toán xếp hạng xuất hiện đồng thời trên cả 2 tab.

### Cách 2: Thiết lập điểm số sát ngưỡng thăng hạng / rớt hạng để kiểm thử hiệu ứng

Để kiểm tra Thăng Hạng hoặc Khiên Bảo Vệ rớt hạng nhanh chóng, có thể dùng SQL cập nhật tạm trên môi trường dev (nhớ khôi phục sau khi test):

```sql
-- Dựng điểm sát ngưỡng thăng hạng (1195 điểm Bạc):
UPDATE player_ratings
SET rating = 1195, games_played = 20, placement_done = true
WHERE user_id = '<user_a_uuid>' AND game_id = 'caro';

-- Dựng điểm sát ngưỡng rớt hạng (1205 điểm Vàng):
UPDATE player_ratings
SET rating = 1205, games_played = 20, placement_done = true
WHERE user_id = '<user_b_uuid>' AND game_id = 'caro';
```

Sau trận đấu:

- Người thắng (1195 $\rightarrow$ 1211) kích hoạt ngay hiệu ứng **🌟 THĂNG HẠNG! 🌟** và pháo giấy confetti.
- Người thua (1205 $\rightarrow$ 1189) kích hoạt ngay cơ chế **🛡️ KHIÊN BẢO VỆ RỚT HẠNG**.
