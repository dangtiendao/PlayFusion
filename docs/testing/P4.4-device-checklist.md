## 2. CÂU LỆNH SQL ĐỐI CHIẾU THỨ HẠNG THỰC TẾ TRÊN DATABASE

### A. Kiểm tra danh sách Top 50 theo đúng thứ tự Tie-break của Repository

```sql
SELECT
  ROW_NUMBER() OVER (ORDER BY pr.rating DESC, pr.user_id ASC) AS rank,
  pr.user_id,
  p.display_name,
  pr.rating,
  pr.games_played,
  pr.wins,
  pr.losses,
  pr.best_rating
FROM public.player_ratings pr
JOIN public.profiles p ON p.user_id = pr.user_id
WHERE pr.game_id = 'caro'
  AND pr.season_id = 1
  AND pr.games_played >= 10
ORDER BY pr.rating DESC, pr.user_id ASC
LIMIT 50;
```

### B. Đối chiếu số thứ hạng cá nhân của User hiện tại (`getMyRank`)

```sql
-- Thay thế <my_user_id> và <my_rating> bằng giá trị của user đang kiểm tra:
SELECT COUNT(*) + 1 AS calculated_rank
FROM public.player_ratings
WHERE game_id = 'caro'
  AND season_id = 1
  AND games_played >= 10
  AND (
    rating > <my_rating>
    OR (rating = <my_rating> AND user_id < '<my_user_id>')
  );
```
