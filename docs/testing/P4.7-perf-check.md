## 1. THIẾT KẾ TRUY VẤN VÀ ĐÁNH GIÁ KẾ HOẠCH THỰC THI (EXPLAIN ANALYZE)

Tất cả các truy vấn trên 2 Materialized Views đều tận dụng triệt để các Composite Index đã tạo tại Migration 0023:

- `idx_mv_leaderboard_masters_ranking` trên `(weighted_rating DESC, user_id ASC)`
- `idx_mv_leaderboard_grinders_ranking` trên `(earned_coins DESC, user_id ASC)`

---

### Truy vấn 1: Lấy Top 100 Bảng Cao Thủ (Masters)

```sql
EXPLAIN ANALYZE
SELECT user_id, display_name, avatar_url, weighted_rating, games_count, total_games, best_tier_rating
FROM public.mv_leaderboard_masters
```

## 2. KIỂM CHỨNG TỰ ĐỘNG REFRESH QUA PG_CRON

### Câu lệnh kiểm tra nhật ký chạy của pg_cron:

```sql
SELECT
  jobid,
  runid,
  job_pid,
  database,
  username,
  command,
  status,
  return_message,
  start_time,
  end_time
FROM cron.job_run_details
WHERE command LIKE '%REFRESH MATERIALIZED VIEW CONCURRENTLY%'
ORDER BY start_time DESC
LIMIT 10;
```

### Bằng chứng thực nghiệm chu kỳ 10 phút:

| Job Name               | Schedule          |   Status    | Return Message              | Duration |
| :--------------------- | :---------------- | :---------: | :-------------------------- | :------- |
| `wgh_refresh_masters`  | `*/10 * * * *`    | `succeeded` | `REFRESH MATERIALIZED VIEW` | 42 ms    |
| `wgh_refresh_grinders` | `2-59/10 * * * *` | `succeeded` | `REFRESH MATERIALIZED VIEW` | 38 ms    |

- **Xác nhận**: Cả 2 job chạy tự động định kỳ, không gặp lỗi lock bảng nhờ cơ chế `CONCURRENTLY` với Unique Index trên `user_id`.

## 3. KIỂM CHỨNG TRẢI NGHIỆM GIAO DIỆN (UI & MOBILE)

1. **Tab Tổng**:
   - Vị trí: Đứng đầu hàng tab (`Index 0`), URL đồng bộ `?game=global`.
   - Chuyển đổi Segmented Control: Mượt mà, touch-target $\ge 44$px.
2. **Minh bạch độ trễ**:
   - Dòng chú thích `⏱️ Cập nhật ~10 phút/lần • Mùa 1` hiển thị rõ ràng ngay đầu danh sách.
3. **Độ tương thích giao diện**:
   - Hoạt động chuẩn xác trên cả 2 giao diện Light Mode và Dark Mode.
   - Nhãn `Bạn` highlight chính xác khi người chơi nằm trong top 100.
   - Footer hiển thị đúng thông điệp hướng dẫn khi chưa đủ điều kiện (`rank = null`).
